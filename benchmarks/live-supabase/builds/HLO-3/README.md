# Acme Notes

Notes your whole team can find. A Next.js (App Router) app built with Once UI.

- `npm run build` and `npm start` run in demo mode with no environment variables.
- `.env.example` lists the Supabase and Stripe variables. Apply `supabase/migrations/` in filename order to enable live accounts, organizations and billing.
- Blog posts live in `content/blog/`.
