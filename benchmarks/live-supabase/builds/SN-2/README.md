# Acme Notes

Acme Notes: notes your whole team can find. A Next.js app with a landing page, blog, Supabase auth, organizations and Stripe billing. See AGENTS.md for where everything lives.

```bash
npm install
npm run dev
```

Everything builds and runs with no environment variables. See `.env.example`
for what each cloud capability needs.

```bash
npm run typecheck
npm run lint
npm run build
```
