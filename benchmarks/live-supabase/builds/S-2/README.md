# Acme Notes

Notes your whole team can find. A Next.js (App Router) app built with Once UI,
Supabase auth and Stripe billing.

```bash
npm install
npm run dev
```

Everything builds and runs with no environment variables (demo mode). See
`.env.example` for the variables, and `supabase/migrations/` for the schema:
the files apply in filename order to a fresh Supabase project.

```bash
npm run typecheck
npm run build
```
