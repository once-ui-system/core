# Acme Notes

Notes your whole team can find. A Next.js (App Router) app on Once UI with
Supabase auth, organizations and Stripe billing.

```bash
npm install
npm run dev
```

Everything builds and runs with no environment variables (demo mode). See
`.env.example`; apply `supabase/migrations/*.sql` in filename order to a fresh
Supabase project.

```bash
npm run typecheck
npm run build
```
