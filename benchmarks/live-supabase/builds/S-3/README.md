# Acme Notes

Notes your whole team can find. A Next.js (App Router) app built with Once UI.

```bash
npm install
npm run dev
```

Everything builds and runs with no environment variables (demo mode). See
`.env.example` for the Supabase and Stripe variables, and `supabase/migrations/`
for the schema (apply in filename order).

```bash
npm run typecheck
npm run build
```
