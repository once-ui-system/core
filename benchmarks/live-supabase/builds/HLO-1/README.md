# Acme Notes

Notes your whole team can find.

Next.js (App Router) with Once UI. Runs in demo mode with no environment variables.

- `.env.example` lists the variables for Supabase (auth, organizations) and Stripe (Team plan, test mode).
- `supabase/migrations/` holds the SQL, applied in filename order to a fresh project.

```bash
npm install
npm run build && npm start
```
