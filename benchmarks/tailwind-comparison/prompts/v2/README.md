# Benchmark v2 tasks (draft)

**Not pre-registered yet.** Eight app-scale tasks over one fictional product (Lumen) and one
seed data file. Nothing here may be run on the real tasks until the pre-registration is
committed (see the v2 plan); the runner can be checked with hand-written fixture apps.

- `briefs.json`: the hand-written briefs, routes, rater checklists, scripted interactions and the
  set's generation budgets (max_tokens 32k, 80 tool calls per attempt).
- `seed.json`: the shared product data; each task gets the slice it names.
- `tasks.json`: generated by `node prompts/v2/build-tasks.mjs`. Don't edit it by hand.

Run: `BENCH_TASKS=prompts/v2/tasks.json node runner/generate-api.mjs --out results/v2-… --tasks all`.
