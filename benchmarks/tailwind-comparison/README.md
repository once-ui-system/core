# Once UI vs Tailwind benchmark

Measures how many AI tokens, and how much code, it takes to build the same UI with
Once UI versus Tailwind CSS (with and without shadcn/ui). Method: [METHODOLOGY.md](./METHODOLOGY.md)
(pre-registered; read it first). Results: [`results/`](./results).

This folder is standalone: it isn't a pnpm workspace package and doesn't change the
library.

## Layout

```
config.json         pinned model, settings, versions, sources, statistics
prompts/            system + user prompt, the one-sentence stack lines, neutralised tasks,
                    repair and rater prompts
arms/{once,shadcn,tailwind}/   Next.js scaffolds (committed lockfiles)
runner/
  setup.mjs         install scaffolds, build each arm's read-only sandbox (work/sandbox)
  generate-api.mjs  full-run generator: Messages API + list_dir/read_file tools + repair loop
  gates.mjs         typecheck → next build → render (console, axe, screenshots)
  metrics.mjs       normalised code size, vendored-code closure, proxy/exact token counts
  pilot-prompt.mjs  pilot fallback: the exact subagent prompt (and repair prompt) per run
  pilot-usage.mjs   pilot fallback: input usage + contamination audit from subagent transcripts
  pilot-gate.mjs    gates every un-gated attempt in a results folder, keeps run.json
  blind.mjs         blinded rating packets (seeded IDs) and unsealing
  report.mjs        tables, medians, IQR, bootstrap CI, claim gates
results/
  pilot.md          pilot report (PRELIMINARY)
  pilot/            raw/<task>/<arm>/run<k>/: prompt, attempt-N.tsx, gate logs, screenshots,
                    usage.json, metrics.json; summary.json, tables.md, ratings.json,
                    blind-key.json, context-manifest.json, voided/ (voided runs, kept)
```

## Reproduce

```bash
# 1. Once UI tarball at the pinned commit (config.json → sources.once_ui)
git worktree add ../core-2.1 d070802900828711bdcf44a1b2bab4754fecf3dd
(cd ../core-2.1 && pnpm install --frozen-lockfile --filter @once-ui-system/core... \
  && cd packages/core && pnpm pack --pack-destination /tmp)

# 2. shadcn/ui source at the pinned commit
git clone https://github.com/shadcn-ui/ui /tmp/shadcn && git -C /tmp/shadcn checkout c2a67849be260701852b0977ba15eb5f3a0ce2a4

# 3. Install and build sandboxes
cd benchmarks/tailwind-comparison
npm ci
node runner/setup.mjs --once-tarball /tmp/once-ui-system-core-2.0.0.tgz --shadcn-src /tmp/shadcn

# 4a. Full run (needs ANTHROPIC_API_KEY)
node runner/generate-api.mjs --out results/full --tasks all

# 4b. Re-gate / re-measure / re-report an existing results folder
node runner/pilot-gate.mjs --results results/pilot     # gates attempts that have no gates.json yet
node runner/metrics.mjs --results results/pilot
node runner/report.mjs --results results/pilot > results/pilot/tables.md

# Self-test of the full-run loop without an API key
node runner/generate-api.mjs --mock --out work/mock-results --tasks 3 --arms A
```

The pilot was generated by Claude Code subagents (METHODOLOGY.md §7): `pilot-prompt.mjs`
prints each run's prompt, `pilot-usage.mjs` reads usage and audits tool calls from the
session's subagent transcripts (session-local, not committed), and the blinded rating packets
are rebuilt with `blind.mjs` (the committed `blind-key.json` maps IDs to runs).

Chromium: the gates use `playwright-core` with the browser at `$CHROMIUM_PATH`
(default `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`).
