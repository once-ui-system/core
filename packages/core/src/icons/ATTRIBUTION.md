# Icon attribution

Once UI's built-in icons are inlined SVG data (`data.ts`), generated by
`scripts/generate-icons.mjs` from the sets below. Each is permissively
licensed; their notices are reproduced here as those licences require.

| Set | Used for | Licence |
| --- | --- | --- |
| [Heroicons 2](https://github.com/tailwindlabs/heroicons) | most UI glyphs (`hi2`) | MIT — © Tailwind Labs |
| [Ionicons 5](https://ionicons.com/) | food, ball, world, gift, symbol, flag (`io5`) | MIT — © Ionic |
| [Lucide](https://lucide.dev/) | wordmark (`lu`) | ISC — © Lucide Contributors |
| [Phosphor](https://github.com/phosphor-icons/core) | radialGauge, linearGauge (`pi`) | MIT — © Phosphor Icons |

The data was obtained through [`react-icons`](https://github.com/react-icons/react-icons)
(MIT), which remains a devDependency for regenerating it and is not shipped to
consumers.

To change the set, edit `scripts/icon-manifest.json` and run
`pnpm generate-icons`.
