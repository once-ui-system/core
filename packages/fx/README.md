# @once-ui-system/fx

The Once UI effects: `RevealFx`, `CountFx`, `CountdownFx`, `TypeFx`, `LetterFx`,
`ShineFx`, `GlitchFx`, `HoloFx`, `TiltFx`, `FlipFx`, `BlobFx`, `MatrixFx`,
`ParticleFx`, `WeatherFx`, `CelebrationFx` and `Effect`. Until 3.0 they were part
of `@once-ui-system/core`; they are built on it and take it as a peer.

```sh
npm install @once-ui-system/core @once-ui-system/fx
```

```tsx
import { RevealFx } from "@once-ui-system/fx";
```

Documentation: [docs.once-ui.com](https://docs.once-ui.com). Migrating from 2.x:
[MIGRATING.md](https://github.com/once-ui-system/core/blob/main/MIGRATING.md).
