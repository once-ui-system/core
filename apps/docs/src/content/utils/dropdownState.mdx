`getLastOpenedDropdown`, `setLastOpenedDropdown` and `clearLastOpenedDropdown` are internal in Once UI 3.0 and no longer exported from `@once-ui-system/core`. They are how an opening dropdown closes the one open before it, which every Once UI dropdown does on its own; there is nothing to call.

See [Migrating from 2.x](https://github.com/once-ui-system/core/blob/main/MIGRATING.md) for the full list of exports that became internal.
