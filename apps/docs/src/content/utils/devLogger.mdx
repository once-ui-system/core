`dev`, the development-only logger, is internal in Once UI 3.0 and no longer exported from `@once-ui-system/core`. Once UI still uses it for its own warnings.

In your own code, log behind a check of your own:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codes={[{ code: `if (process.env.NODE_ENV === "development") {
  console.log("Debug info:", data);
}`, language: "tsx", label: "Development-only logging" }]}
/>

See [Migrating from 2.x](https://github.com/once-ui-system/core/blob/main/MIGRATING.md) for the full list of exports that became internal.
