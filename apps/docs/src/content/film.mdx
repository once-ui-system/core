## About

Once UI Film is part of [Studio on once-ui.com](https://once-ui.com/dashboard/film). Its scenes are drawn from the components you already ship, such as charts, mascots, product pages and effects, so a launch film shows real UI. Every scene plays live in Studio. You tweak its props in the Customize panel and copy the film.json. Pro and Indie members also copy the engine and scene source to render on their own machine.

## Direct a film from your agent

Connect the hosted Once UI MCP and ask for a film ("a 16 second launch film for our 3.1 release, with our mascot"):

```bash
claude mcp add --transport http once-ui https://once-ui.com/api/mcp
```

The agent reads the scenes with `film_list_scenes`, writes a film.json and checks it with `film_check`. `film_open` hands back a link that opens the cut in Studio. The film travels inside that link, so nothing is stored. See [the hosted MCP](/ai-coding) for the full tool list and sign-in.

## film.json

```json
{
  "fps": 60,
  "accent": "#3fe3f2",
  "look": { "brand": "cyan", "accent": "blue", "solid": "color", "solidStyle": "flat", "border": "playful", "surface": "filled" },
  "slate": { "sub": "Once UI 3.0", "footer": { "text": "npx once-ui create", "at": 13.2, "until": 16.1 } },
  "shots": [
    { "scene": "big-word", "props": { "word": "3.0" }, "seconds": 1.4, "in": "cut", "out": "whip" },
    { "scene": "headline", "props": { "text": "Tell your AI.\nGet real UI.", "highlight": "real UI" }, "seconds": 2.6 },
    { "scene": "mascot", "props": { "username": "once-ui", "line": "Even I'm a component." }, "seconds": 2.8, "in": "cut" },
    { "scene": "lockup", "props": { "name": "Once UI 3.0", "line": "Free and open source", "icon": "sparkle" }, "seconds": 3.6, "in": "slam", "out": "cut" }
  ]
}
```

| Field | What it sets |
| --- | --- |
| `accent` | The one vibrant colour on a black stage |
| `look` | The Once UI style the components inside the scenes use |
| `slate` | Small type that stays on screen: `sub`, a `caption` per shot, a timed `footer` |
| `shots` | The scenes in order. Each has `scene`, `props`, `seconds`, `in` (`whip`, `slam`, `rise`, `blur`, `zoom`, `cut`) and `out` (`whip`, `push`, `blur`, `sink`, `cut`) |
| `shots[].behind` | A huge, dim word behind the shot |
| `shots[].layers` | Other scenes on their own clock over or under the shot: `at`, `until`, `place`, `opacity`, `blend`, `fade` |
| `backdrop` | A scene that runs under the whole film |

A prop left out takes the scene's default. The house loop is 16.4 seconds and a whip takes 0.32 seconds. The film's length is the sum of its shots.

## Your mascot

The `mascot` scene puts one mascot on stage. Set `username` to a Once UI username to show that person's own mascot, the one they saved in Studio's character designer. Set it to `once-ui` or `quasar` for the brand mascots. In Studio, **Use my mascot** fills in your own.

## Rendering

Studio's **Render** tab has the Remotion setup: one composition per shape, 1920 × 1080 and 1080 × 1920 at 60 fps, from the same film.json. Once UI ships compiled CSS modules, so the setup turns on css-loader's module mode, and it uses SwiftShader so the effects render on machines without a GPU.
