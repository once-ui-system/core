The `Select` component offers a dropdown menu for selecting from a list of options. It's built on top of the `DropdownWrapper` and `Input` components, providing a consistent user experience with other form controls.

<CodeBlock
    marginTop="16"
    marginBottom="24"
    preview={
        <Select
            fillWidth
            id="basic-select"
            label="Choose a country"
            options={[
                { label: "United States", value: "us" },
                { label: "Canada", value: "ca" },
                { label: "United Kingdom", value: "uk" },
                { label: "Australia", value: "au" }
            ]}
        />
    }
    codes={[
        {
            code:
`const [selectedCountry, setSelectedCountry] = useState("");

<Select
    id="basic-select"
    label="Choose a country"
    value={selectedCountry}
    options={[
      { label: "United States", value: "us" },
      { label: "Canada", value: "ca" },
      { label: "United Kingdom", value: "uk" },
      { label: "Australia", value: "au" }
    ]}
    onSelect={(country) => setSelectedCountry(country as string)}
/>`,
            language: "tsx",
            label: "Select"
        }
    ]}
/>

## Multiple selection

Set `multiple` to allow selecting more than one option. The `value` and `onSelect` callbacks receive arrays when multiple mode is enabled.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codes={[
    {
      code:
`const [tags, setTags] = useState<string[]>([]);

<Select
  id="tags-select"
  label="Tags"
  multiple
  value={tags}
  options={[
    { label: "Design", value: "design" },
    { label: "Engineering", value: "engineering" },
    { label: "Product", value: "product" },
  ]}
  onSelect={(value) => setTags(value as string[])}
/>`,
      language: "tsx",
      label: "Multiple selection"
    }
  ]}
/>

## Aligned

`position="aligned"` opens the list with the selected option sitting on the field, and the others above and below it in their own order, as macOS draws a pop-up button. With nothing picked, the first option sits there. A long list shows a few rows on each side and scrolls the rest. It suits short, settings-style choices. Near the top or bottom of the screen, and on a searchable or multiple Select, it opens as a dropdown instead.

<CodeBlock

## Toolbar size

`size="xxs"` draws a 32px field, the height of a `size="s"` Button, for a filter in a toolbar. The label shows as the placeholder, and a searchable Select opens an `xxs` search field to match. Every other size keeps the `s` search field it had.
