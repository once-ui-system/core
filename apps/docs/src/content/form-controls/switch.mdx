The `Switch` component provides a toggle control for binary states, featuring a sliding animation when toggled. It's commonly used for enabling or disabling features and settings.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={<BasicSwitch />}
  codes={[
    {
      code:
`<Switch
    label="Enable notifications"
    description="Receive updates about new features and improvements"
    checked={isChecked}
    onCheckedChange={() => setIsChecked(!isChecked)}
/>`,
      language: "tsx",
      label: "Switch"
    }
  ]}
/>

## State

Control the switch state with the `checked` prop. `onCheckedChange` receives the state the switch moves to, so the setter can be passed straight in.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={<SwitchWithFeedback />}
  codes={[
    {
      code:
`const [isChecked, setIsChecked] = useState(false);

<Switch
    label={isChecked ? "Feature is now enabled" : "Feature is currently disabled"}
    checked={isChecked}
    onCheckedChange={setIsChecked}
/>`,
      language: "tsx",
      label: "State"
    }
  ]}
/>

## Uncontrolled

Leave out `checked` and the switch keeps its own state, starting from `defaultChecked`. `onCheckedChange` still reports every change, and with a `name` the switch submits its value with a form.

## Validation and size

`error` marks the Switch invalid (a danger border and `aria-invalid`);
`errorMessage` shows under it, linked with `aria-describedby`, and marks it
invalid too. `size` (`s`, `m`, `l`) scales the control and its text; left out,
it takes the enclosing `Form`'s `size`, as `Input` does.
