`InteractiveDetails` is internal in Once UI 3.0. It is the label and description block `Checkbox`, `RadioButton` and `Switch` draw, and it is no longer exported from `@once-ui-system/core`.

Pass `label` and `description` to the control instead:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={<Checkbox label="Email updates" description="One message a month, no more." />}
  codes={[{ code: `<Checkbox label="Email updates" description="One message a month, no more." />`, language: "tsx", label: "Checkbox" }]}
/>

See [Migrating from 2.x](https://github.com/once-ui-system/core/blob/main/MIGRATING.md) for the full list of exports that became internal.
