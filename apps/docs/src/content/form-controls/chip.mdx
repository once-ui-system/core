Chips are compact elements that represent discrete information, selections, or filters. They help users make selections, filter content, or trigger actions in a space-efficient way.

## State

Chips can be in a selected or unselected state to indicate active filters or selections. You can use the `onClick` prop to make the chip interactive.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <InteractiveChipExample />
  }
  codes={[
    {
      code:
`const [selected, setSelected] = useState<boolean>(true);

<Chip 
    label="Clickable" 
    selected={selected}
    onClick={() => setSelected(!selected)} 
/>`,
      language: "tsx",
      label: "Interactive"
    }
  ]}
/>

## Prefix & Suffix

Enhance chips with prefix icons to improve visual communication. `suffixIcon` puts one after the label, such as a chevron on a chip that opens a menu.

## Removable

Chips can include a remove button to allow users to dismiss or remove the chip. Click the remove button to see toast notifications.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <RemovableChipsExample />
  }
  codes={[
    {
      code:
`const { addToast } = useToast();
const [chips, setChips] = useState<{ id: string; label: string; icon?: IconName }[]>([
    { id: "1", label: "React", icon: "code" },
    { id: "2", label: "TypeScript", icon: "code" },
    { id: "3", label: "Next.js" }
]);

const handleRemove = (id) => {
    const chipToRemove = chips.find(chip => chip.id === id);
    setChips(chips.filter(chip => chip.id !== id));
    
    addToast({
      variant: "danger",
      message: "Removed " + chipToRemove.label + " chip"
    });
};

<Row gap="8" wrap>
    {chips.map(chip => (
      <Chip
        key={chip.id}
        label={chip.label}
        prefixIcon={chip.icon}
        onRemove={() => handleRemove(chip.id)}
      />
    ))}
</Row>`,
      language: "tsx",
      label: "Removable"
    }
  ]}
/>

When removing is the chip's only action, `interactive={false}` makes its label plain text, so it is not a second tab stop that does nothing. TagInput's tags work this way.
