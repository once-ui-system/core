`Chip` folded into [Tag](/components/tag) in Once UI 3.0 and is no longer exported. A Tag given `selected`, `onClick` or `onRemove` is the same toggle, with `aria-pressed` and an optional remove button:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <InteractiveChipExample />
  }
  codes={[
    {
      code:
`// 2.x
<Tag label="Design" selected={on} onClick={toggle} removeButtonProps={{ tooltip: "Remove" }} onRemove={remove} />

// 3.0
<Tag label="Design" selected={on} onClick={toggle} removeButtonProps={{ tooltip: "Remove" }} onRemove={remove} />`,
      language: "tsx",
      label: "Chip → Tag"
    }
  ]}
/>

`selected` now defaults to **false**: a 2.x `<Tag selected label="x" />` was drawn and announced as selected. The 3.0 codemod writes `selected` where it was left out, so migrated chips keep their look, and renames `iconButtonProps` to `removeButtonProps`. See [Tag: Toggle](/components/tag#toggle).
