The `Checkbox` component provides a selectable control that can be toggled between checked, unchecked, and indeterminate states. Its `label` and `description` are drawn the same way as on `RadioButton` and `Switch`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Checkbox
      label="Accept terms and conditions"
      description="By checking this box, you agree to our terms of service."
    />
  }
  codes={[
    {
      code:
`<Checkbox
    label="Accept terms and conditions"
    description="By checking this box, you agree to our terms of service."
/>`,

    }
  ]}
/>

## State

Use the `checked` prop with React state to create controlled checkboxes. `onCheckedChange` receives the state the checkbox moves to, so the setter can be passed straight in.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Checkbox
      label="Controlled checkbox"
    />
  }
  codes={[
    {
      code:
`const [checked, setChecked] = useState(false);

<Checkbox
    label="Controlled checkbox"
    checked={checked}
    onCheckedChange={setChecked}
/>

// You can also update the state programmatically
const handleReset = () => setChecked(false);`,
      language: "tsx",
      label: "State"
    }
  ]}
/>

## Indeterminate

The checkbox can display an indeterminate state, useful for parent checkboxes that control a group of child checkboxes.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={<IndeterminateCheckboxExample />}
  codes={[
    {
      code:
`const [items, setItems] = useState([
    { id: 1, label: 'Item 1', checked: true },
    { id: 2, label: 'Item 2', checked: false },
    { id: 3, label: 'Item 3', checked: true }
]);

const allChecked = items.every(item => item.checked);
const someChecked = items.some(item => item.checked);
const isIndeterminate = someChecked && !allChecked;

const toggleAll = () => {
    const newCheckedState = !allChecked;
    setItems(items.map(item => ({
      ...item,
      checked: newCheckedState
    })));
};

<Checkbox
    label="Select all items"
    checked={allChecked || isIndeterminate}
    indeterminate={isIndeterminate}
    onCheckedChange={toggleAll}
/>

{items.map(item => (
    <Checkbox
      key={item.id}
      label={item.label}
      checked={item.checked}
      onCheckedChange={() => {
        setItems(items.map(i => 
          i.id === item.id ? { ...i, checked: !i.checked } : i
        ));
      }}
    />
))}`,
      language: "tsx",
      label: "Indeterminate"
    }
  ]}
/>

## Validation and size

`error` marks the Checkbox invalid (a danger border and `aria-invalid`);
`errorMessage` shows under it, linked with `aria-describedby`, and marks it
invalid too. `size` (`s`, `m`, `l`) scales the control and its text; left out,
it takes the enclosing `Form`'s `size`, as `Input` does.
