`PasswordInput` is [Input](/form-controls/input) with one addition: a control in
the suffix that switches the field between masked and visible. Everything else —
label, description, validation, size — behaves identically.

## API reference

It adds no props of its own. The full surface is [Input](/form-controls/input)'s.
