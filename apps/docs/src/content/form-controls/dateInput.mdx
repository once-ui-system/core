The `DateInput` component provides an enhanced date picker that combines an input field with a dropdown calendar interface. It allows users to easily select dates with optional time selection.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Row fillWidth height="24rem" horizontal="center" vertical="start">
      <DateInputExample />
    </Row>
  }
  codes={[
    {
      code:
`const [date, setDate] = useState<Date | undefined>(new Date());
  
const handleDateChange = (newDate: Date) => {
    setDate(newDate);
};

<DateInput
    id="date-input-example"
    label="Select Date"
    value={date}
    onValueChange={handleDateChange}
/>`,
      language: "tsx",

## Range

With `range`, the field becomes two, a start and an end, over one calendar that picks both (2.x's `DateRangeInput`). `value`, `defaultValue` and `onValueChange` then take a `DateRange`, `{ startDate, endDate }`; `startLabel` and `endLabel` name the fields, and `id` is the base of their ids, `{id}-start` and `{id}-end`.

## Features

- **Calendar Interface**: Visual calendar for easy date selection
- **Time Selection**: Optional time picker for selecting hours and minutes
- **Formatted Display**: Displays selected date in a readable format
- **Dropdown Integration**: Uses `DropdownWrapper` for a clean UI experience

## Toolbar size

`size="xxs"` draws a 32px field, the height of a `size="s"` Button, for a date filter in a toolbar.

  marginTop="16"
