`NumberInput` is [Input](/form-controls/input) for numbers. It adds stepper
controls and clamps what can be typed, so the value reaching `onChange` is
already a number within range — no parsing, no `NaN`.

  marginTop="16"

const handleChange = (newValue: number) => {
    setValue(newValue);
};

<NumberInput
    id="quantity"
    label="Quantity"
    value={value}
    onChange={handleChange}
    min={0}
    max={100}
    step={1}
/>`,
