`NumberInput` is [Input](/form-controls/input) for numbers. It adds stepper
controls and clamps what can be typed, so the value reaching `onValueChange` is
already a number within range — no parsing, no `NaN`.

## Following the value

The field follows its `value` prop after mount, so a number changed somewhere
else (an undo, a reset, a drag on a timeline) shows up in it. There is no need
to remount it with a `key`. It does not rewrite what the user is typing: a
partial entry such as `-` or `1.` stays as typed until it reads as a number.
