`TagInput` holds an array rather than a string. Each entry renders as a chip
that can be removed on its own, and typing a new one appends to the array.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={<TagInputExample />}
  codes={[
    {
      code:
`const [tags, setTags] = useState<string[]>(["React", "Next.js"]);

<TagInput
    id="interests"
    value={tags}
    onChange={setTags}
    placeholder="Add interest"
    suffix={<Kbd position="absolute" top="12" right="12">Enter</Kbd>}
/>`,
      language: "tsx",
      label: "TagInput"
    }
  ]}
/>

## Uncontrolled

Leave out `value` and the input keeps its own list, starting from `defaultValue`. `onChange` still receives every new array.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={<TagInput id="topics" label="Topics" defaultValue={["Design", "Code"]} />}
  codes={[
    {
      code:
`<TagInput
    id="topics"
    label="Topics"
    defaultValue={["Design", "Code"]}
/>`,
      language: "tsx",
      label: "Uncontrolled"
    }
  ]}
/>

## Toolbar size

`size="xxs"` starts the field at 32px, the height of a `size="s"` Button. It grows as chips are added, like every size.

<CodeBlock
  marginTop="16"
  marginBottom="24"

      code:
`const [tags, setTags] = useState<string[]>(["React", "Next.js"]);

<TagInput
    id="interests"
    placeholder="Add interest"
    size="xxs"
    value={tags}
    onChange={setTags}
