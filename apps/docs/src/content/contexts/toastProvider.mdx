The `ToastProvider` wraps your app to provide access to `useToast`, allowing any component to trigger lightweight, dismissible toast messages globally.

## Simple setup

Wrap your app with `ToastProvider` to activate toast functionality.

## Advanced setup

We recommend using a `Providers` component to wrap your app. You can choose to display toasts at the top or bottom based on breakpoints.

Use the `useToast()` hook to display notifications from anywhere in your app:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codeHeight="24rem"
  isCollapsible={true}
  lineNumbers
  preview={
    <ToastExample />
  }
  codes={[
    {
      code:
`"use client";

import React, { useState } from "react";
import { Button, Row, useToast } from "@once-ui-system/core";

export function ToastExample() {
    const { addToast } = useToast();
    const [count, setCount] = useState(0);

    const handleAddToast = (tone: 'success' | 'danger' | 'warning' | 'info') => {
      setCount(prev => prev + 1);
      const labels: Record<string, string> = {
        success: 'Success!',
        danger: 'Error!',
        warning: 'Warning!',
        info: 'Info',
      };
      addToast({
        tone,
        message: "Toast #" + (count + 1) + " - " + labels[tone],
        action: (tone === 'danger' || tone === 'warning') ? (
          <Button size="s" onClick={() => addToast({ tone: 'success', message: 'Retry successful!' })}>
            Retry
          </Button>
        ) : undefined,
      });
    };

    return (
      <Row gap="8" wrap>
        <Button size="s" onClick={() => handleAddToast('success')}>
          Show Success
        </Button>
        <Button size="s" variant="secondary" onClick={() => handleAddToast('danger')}>
          Show Error
        </Button>
        <Button size="s" variant="tertiary" onClick={() => handleAddToast('warning')}>
          Show Warning
        </Button>
        <Button size="s" variant="tertiary" onClick={() => handleAddToast('info')}>
          Show Info
        </Button>
      </Row>
    );

}`,
language: "tsx",
label: "useToast"
}
]}
/>

## Duration and removing a toast

`addToast` returns the new toast's id. Pass it to `removeToast` to take the toast down before it times out, such as a "Saving…" toast once the save is done. Each toast stays up for its `duration` in milliseconds: 6000 by default, and `Infinity` keeps it up until it is closed. The countdown pauses while the toast is hovered or has focus, and resumes with the time that was left.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codes={[
    {
      code:
`const { addToast, removeToast } = useToast();

async function save() {
  const saving = addToast({ tone: "info", message: "Saving…", duration: Infinity });
  await saveDocument();
  removeToast(saving);
  addToast({ tone: "success", message: "Saved" });
}`,
      language: "tsx",
      label: "Save with progress",
    },
  ]}
/>

`addToast` and `removeToast` keep the same identity for the provider's lifetime, so an effect can list them as dependencies without running again each time a toast appears. There is no need to hold them in a ref.

## The toast stack

The `ToastProvider` renders the toast stack itself, from the current list of toasts. The stack is internal in 3.0 (2.x exported it as `Toaster`), so there is nothing else to mount.
