The `LayoutProvider` component is a context provider that creates a listener for the Flex and Grid components to track window size.

## Simple setup

Wrap your app with `LayoutProvider`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codeHeight={24}
  lineNumbers
  codes={[
    {
      code:
`<LayoutProvider>
    {children}
</LayoutProvider>`,
      language: "tsx",
      label: "layout.tsx"
    }
  ]}
/>

## Advanced setup

You can pass a breakpoint object to the `LayoutProvider`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codeHeight={32}
  lineNumbers
  codes={[
    {
      code:
`import { IconProvider, ToastProvider, ThemeProvider, DataThemeProvider, LayoutProvider } from "@once-ui-system/core";

export function Providers({ children }: {
    children: React.ReactNode
}) {
    return (
      <LayoutProvider
        breakpoints={{
          s: 640,
          m: 1024,
          l: 1200,
        }}
      >
        <ThemeProvider>
          <DataThemeProvider>
            <ToastProvider>
              <IconProvider>
                {children}
              </IconProvider>
            </ToastProvider>
          </DataThemeProvider>
        </ThemeProvider>
      </LayoutProvider>
    );
}`,
      language: "tsx",
      highlight: "1,7-13",
      label: "Providers.tsx",
    },
  ]}
/>

## useLayout

`useLayout()` reads the resolved breakpoint state. Use it when a decision cannot
be expressed with the responsive props — mounting a different component per
breakpoint, say, rather than styling one. It throws outside a `LayoutProvider`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codes={[
    {
      code:
`const { currentBreakpoint, maxWidth } = useLayout();

// Below the m breakpoint, render the sheet instead of the popover.
return maxWidth("s") ? <Sheet {...props} /> : <Popover {...props} />;`,
      language: "tsx",
      label: "useLayout"
    }
  ]}
/>

`width` is `0` on the server and on the first client render, so branch on it
only inside an effect — or branch on `currentBreakpoint`, which is resolved
before paint.
