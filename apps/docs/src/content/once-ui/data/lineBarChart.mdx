The `LineBarChart` component provides a way to display line charts with interactive features, including hover effects, click events, and custom styling options. It supports various customization options including different chart types, color schemes, and interactive features.

<LineBarChart
  marginTop="16"
  marginBottom="24"
  title="Traffic Per Weekday"
  description="How many users we had per weekday"
  axis="both"
  legend={{
    position: "bottom-center"
  }}
  series={[
    { key: "Traffic", color: "blue" },
    { key: "Conversions", color: "indigo" }
  ]}
  data={[
    { name: "Mon", Traffic: 4500, Conversions: 2190 },
    { name: "Tue", Traffic: 5200, Conversions: 4230 },
    { name: "Wed", Traffic: 4800, Conversions: 3250 },
    { name: "Thu", Traffic: 5900, Conversions: 3280 },
    { name: "Fri", Traffic: 6800, Conversions: 4320 },
    { name: "Sat", Traffic: 4800, Conversions: 3190 },
    { name: "Sun", Traffic: 3900, Conversions: 3170 },
  ]}
/>
## Which series is which

Order decides the shape: **the first series is drawn as the line, the second as
the bars.** There is no prop for it, and only the first two series are drawn —
a third is ignored.

## Both series share one y axis

There is a single y axis, so the two measures are plotted against the same
scale. That makes the chart a comparison of two quantities of **comparable
magnitude** — sessions against conversions, budget against spend — not a way to
overlay a rate on a volume.

Pair a percentage with a count and the percentage collapses onto the baseline:
it is not missing, it is drawn at 4 on an axis that runs to 8000. If that is
the chart you want, normalise the small series into the same units first, or
put the two measures in separate charts.

<LineBarChart
  marginTop="16"
  marginBottom="24"
  title="Budget against spend"
  description="Two measures on one scale — which is what this chart is for"
  axis="both"
  legend={{ position: "bottom-center" }}
  series={[
    { key: "Budget", color: "cyan" },
    { key: "Spend", color: "indigo" }
  ]}
  data={[
    { name: "Jan", Budget: 52000, Spend: 41000 },
    { name: "Feb", Budget: 52000, Spend: 47000 },
    { name: "Mar", Budget: 52000, Spend: 55000 },
    { name: "Apr", Budget: 60000, Spend: 58000 },
    { name: "May", Budget: 60000, Spend: 62000 },
    { name: "Jun", Budget: 60000, Spend: 51000 }
  ]}
/>

## API reference

The line's shape comes from `curve` and the bars' thickness from `barWidth` —
the same props as [`LineChart`](/once-ui/data/lineChart) and
[`BarChart`](/once-ui/data/barChart), which is what makes swapping between the
three cheap.
