`BlobFx`, `MatrixFx`, `WeatherFx`, `ParticleFx` and `CelebrationFx` all do the same
structural job: paint a full-bleed decorative layer behind their content. In
practice they are alternatives to each other, but swapping one for another meant
changing an import and rewriting the positioning at every call site.

`Effect` picks between them **by value**. A template can expose its aesthetic as
one setting, and `type="none"` renders the content with no layer at all.

## Content sits above the layer

Children render on top of the effect, and the wrapper is identical for every
`type` — including `"none"`. That is what makes the swap safe: changing the
effect changes the look and nothing else about the layout.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  previewPadding="0"
  preview={
    <Effect type="matrix" height={20} radius="l" colors={["brand-solid-medium"]}>
      <Column fillWidth center gap="8">
        <Heading variant="display-strong-l" onBackground="neutral-strong">
          One setting
        </Heading>
        <Text variant="body-default-m" onBackground="neutral-weak">
          Swap the aesthetic without touching the page
        </Text>
      </Column>
    </Effect>
  }
  codes={[
    {
      code:
`<Effect type="matrix" height={20} radius="l" colors={["brand-solid-medium"]}>
    <Column fillWidth center gap="8">
      <Heading variant="display-strong-l">One setting</Heading>
      <Text variant="body-default-m">
        Swap the aesthetic without touching the page
      </Text>
    </Column>
</Effect>`,
      language: "tsx",
      label: "Layered content"
    }
  ]}
/>

## Shared and per-effect settings

`colors` and `speed` apply across the set: `ParticleFx` takes a single colour, so
it uses the first entry, and `blob` is seeded rather than timed and ignores both.
Anything an individual effect needs goes in its own block, which is only read
when that effect is the one showing — so all of them can be configured up front
and still switched with one prop.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  previewPadding="0"
  preview={
    <Effect
      type="weather"
      height={16}
      radius="l"
      colors={["accent-solid-medium"]}
      weather={{ type: "snow", intensity: 0.6 }}
      matrix={{ flicker: true }}
    />
  }
  codes={[
    {
      code:
`<Effect
  type="weather"
  colors={["accent-solid-medium"]}
  weather={{ type: "snow", intensity: 0.6 }}
  matrix={{ flicker: true }}
/>`,
      language: "tsx",
      label: "Per-effect settings"
    }
  ]}
/>
