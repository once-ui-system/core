TypeFx creates a realistic typewriter animation that types out text character-by-character. When multiple words are provided, it automatically types, holds, deletes, and cycles through them. With `mode="fade"` it [fades the letters in](#fade-mode) instead.

        charDuration={80}

## Custom trigger

Use the `custom` trigger to programmatically control when the typing animation starts.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Column gap="16">
      <TypeFxCustomExample />
    </Column>
  }
  codes={[
    {
      code:
`function TypeFxCustomExample() {
  const triggerFnRef = useRef<(() => void) | null>(null);

  return (
    <>
      <TypeFx
        words={["Click the button", "to start typing", "this animation"]}
        charDuration={60}
        hold={1500}
        trigger="custom"
        onTrigger={(fn) => {
          triggerFnRef.current = fn;
        }}
      />
      <Button onClick={() => triggerFnRef.current?.()}>
        Start typing
      </Button>
    </>
  );
}`,
      language: "tsx",
      label: "Custom trigger"
    }
  ]}
/>

## Fade mode

With `mode="fade"`, TypeFx shows the whole text at once and fades it in letter by letter, from blur to focus, instead of typing it (2.x's `FadingLettersFx`). `state` plays a phase, `delay` offsets the start and `charDuration` sets the gap between letters; an array of `words` is joined with spaces.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  reloadButton
  preview={

      align="center"
      words="Welcome to Once UI"
      state="entering"
      textVariant="display-strong-m"
    />

### States

`state` takes one of three phases, and the parent drives it: `entering` (the default), `visible` and `exiting`.

#### Entering
Letters fade in sequentially with a blur-to-focus effect and scale transformation. Each letter has a calculated delay based on its position in the word and message.

#### Visible
Letters remain static without animation. Use this state when no animation is active.

#### Exiting
Letters fade out with blur and scale effects. Each letter has a random exit delay for an organic dissolution effect.

### Timing

Each letter's entry delay adds up from:

- **Start**: `delay`
- **Word**: `wordIdx × 200ms`
- **Letter**: `letterIdx × charDuration` (default 40ms in fade mode)

Exiting, each letter waits a random 0 to 400ms.
