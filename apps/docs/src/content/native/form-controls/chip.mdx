`Chip` folded into [Tag](/native/components/tag) in Once UI 3.0, as it did on the [web](/form-controls/chip), and `@once-ui-system/native` no longer exports it. A Tag given `selected`, `onClick` (or `onPress`) or `onRemove` is the same toggle, with a remove button when it has `onRemove`. `selected` now defaults to false.
