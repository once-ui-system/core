`SubmitButton` takes every [`Button`](/native/components/button) prop plus `pendingLabel` and `pending`, as on the web. Inside a `Form` with `as="form"` it calls the form's `onSubmit`; while the returned promise runs it shows a spinner, swaps to `pendingLabel` and ignores taps. See the [web SubmitButton](/form-controls/submitButton) for the same component in the browser.

Outside a form, or for a submit the form does not track, set `pending` yourself.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `pendingLabel` | `string` | | The label while the form submits. |
| `pending` | `boolean` | | Forces the pending look. |
| `onPress` / `onClick` | `() => void` | | Called before the form submits. Not called while pending. |

Every other prop is `Button`'s.
