`Textarea` is an [Input](/native/form-controls/input) that takes several lines. It takes every Input prop, with `multiline` set and the text aligned to the top. `lines` sets how tall the field is when it is empty. See the [web Textarea](/form-controls/textarea) for the same component in the browser.

## Error and character count

codes={[
  {
    code:
`import { useState } from "react";
import { Textarea } from "@once-ui-system/native";

export function Review() {
  const [review, setReview] = useState("");
  return (
    <Textarea
      label="Review"
      value={review}
      onChangeText={setReview}
      maxLength={280}
      characterCount
      error={review.length > 0 && review.length < 20}
      errorMessage="Write at least 20 characters."
    />
  );
}`,
    language: "tsx",
    label: "Review.tsx"
  }
]} />

## Differences from the web

- There is no `resize` prop or handle. `lines` sets the empty field's height.
- Use `onChangeText` for the value, as with `Input`.

## API reference

Takes every [Input](/native/form-controls/input) prop.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `lines` | `number` | `3` | The field's height when empty, in lines of `body-default-m`. |
| `label` | `string` | | Floats above the text once the field is focused or filled. |
| `error` | `boolean` | `false` | Draws the field in the danger colour and shows `errorMessage`. |
| `errorMessage` | `ReactNode` | | Shown under the field while `error` is true. |
| `description` | `ReactNode` | | A hint under the field. |
| `characterCount` | `boolean` | | Shows how many characters are left. Needs `maxLength`. |
| `disabled` | `boolean` | `false` | Dims the field and stops editing. |
| `inputStyle` | `TextStyle` | | Style for the `TextInput`, merged after the line height. |
