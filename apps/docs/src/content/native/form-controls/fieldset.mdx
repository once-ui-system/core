`Fieldset` takes the same props as on the web (`legend`, `description`, `disabled`, plus `Form`'s `density`, `columns` and `size`). The legend is a heading a screen reader can jump to, the fields inside are laid out by a [`Form`](/native/form-controls/form), and `disabled` disables every field inside. See the [web Fieldset](/form-controls/fieldset) for the same component in the browser.

## Differences from the web

- `disabled` reaches `Input` and the fields built on it (`Textarea`, `Select`, `NumberInput`, `PasswordInput`). Other controls take their own `disabled`.
- `name` is left out: React Native has no form data.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `legend` | `ReactNode` | | The section's heading. |
| `description` | `ReactNode` | | A line under the legend. |
| `disabled` | `boolean` | | Disables the fields inside. |
| `density` | `"stacked" \| "tight" \| "spacious"` | `"tight"` | As on `Form`. |
| `columns` | `number \| { xl?, l?, m?, s?, xs? }` | `1` | As on `Form`. |
| `size` | `"xs" \| "s" \| "m" \| "l" \| "xl"` | | As on `Form`; the outer form's size carries in. |
| `span` | `number` | | Columns to take inside an outer `Form`. |
