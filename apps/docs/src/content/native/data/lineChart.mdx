`LineChart` draws a line for each series across the rows of `data`, with the area under it filled. It sits on a bordered card with an optional title and description, a legend and axis labels, and draws with react-native-svg. It takes the same `data` and `series` as the [web LineChart](/data/lineChart). Tap a row to see its values.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { LineChart } from "@once-ui-system/native";

const data = [
  { date: "2026-01-01", visits: 320, orders: 120 },
  { date: "2026-02-01", visits: 410, orders: 150 },
  { date: "2026-03-01", visits: 380, orders: 140 },
  { date: "2026-04-01", visits: 520, orders: 190 },
];

export function Traffic() {
  return (
    <LineChart
      title="Traffic"
      description="Visits and orders per month"
      data={data}
      series={[
        { key: "visits", color: "blue" },
        { key: "orders", color: "aqua" },
      ]}
      date={{ format: "MMM" }}
    />
  );
}`,
    language: "tsx",
    label: "LineChart"
  }
]} />

## Data and series

Each row of `data` is an object. The x value is the first key that is not a series, here `date`. Each entry in `series` names a key that holds a number and gives it a `color`. A color can be a data color (`"blue"`, `"emerald"` and the other schemes), any theme color token, or a raw `#hex` value. If you leave out `color`, the series gets a distinct scheme, as on the web. Rows without a number for a series are skipped, and the line joins their neighbours.

## Curve

`curve` sets how the line runs between points. It takes the names of d3's curves: `natural` (the default), `monotone`, `linear`, `step`, `stepBefore`, `stepAfter`, `bump` and `basis`. `monotone` never overshoots the data, which suits values that can't go below zero.

  return (
    <Column gap="16">
      <LineChart data={data} series={{ key: "sales" }} curve="monotone" />

    </Column>

}`,

  }

## Variant

`variant` fills the area under the line with a fading `gradient` (the default), a solid `flat` color or nothing (`outline`). `data-viz-style="sequential"` draws every series in shades of the brand color, and `divergent` uses core's diverging palette.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { LineChart } from "@once-ui-system/native";

export function Outline({ data }: { data: { day: string; sales: number }[] }) {
  return <LineChart data={data} series={{ key: "sales" }} variant="outline" grid="y" />;
}`,
    language: "tsx",
    label: "Outline"
  }
]} />

## Dates

`date.start` and `date.end` keep only the rows between them. `date.format` writes date x values, given as a `Date` or an ISO string, with the common date-fns tokens: `yyyy`, `yy`, `MMMM`, `MMM`, `MM`, `M`, `dd`, `d`, `EEEE`, `EEE`, `HH` and `mm`.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { LineChart } from "@once-ui-system/native";

export function FirstQuarter({ data }: { data: { date: string; visits: number }[] }) {
  return (
    <LineChart
      data={data}
      series={{ key: "visits" }}
      date={{ start: new Date(2026, 0, 1), end: new Date(2026, 2, 31), format: "MMM d" }}
    />
  );
}`,
    language: "tsx",
    label: "Dates"
  }
]} />

## Numeric x axis

By default the rows are spread evenly, the first on the left edge and the last on the right. Set `xAxisType="number"` to place each row by its x value instead, over `xDomain` or the values' range.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { LineChart } from "@once-ui-system/native";

export function Temperature() {
  return (
    <LineChart
      data={[
        { hour: 6, temp: 12 },
        { hour: 9, temp: 16 },
        { hour: 15, temp: 22 },
        { hour: 21, temp: 17 },
      ]}
      series={{ key: "temp", color: "orange" }}
      xAxisType="number"
      xDomain={[0, 24]}
    />
  );
}`,
    language: "tsx",
    label: "Numeric x"
  }
]} />

## Tooltip

Tap a row to show a line through it, a dot on each series and a tooltip with the values. Tap the same row again to hide it, or another row to move it. `tooltip={false}` turns tapping off. Screen readers read each row as a button labelled with its values.

## Loading, empty and error states

`loading` shows a spinner instead of the plot. With no rows, the chart shows `emptyState`, and with `error` it shows `errorState`. Both take a string or your own element.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { LineChart } from "@once-ui-system/native";

export function Empty() {
  return <LineChart title="Visits" data={[]} series={{ key: "visits" }} emptyState="No visits yet" />;
}`,
    language: "tsx",
    label: "Empty"
  }
]} />

## Size

The chart fills its parent's width, measured with `onLayout`, so the plot redraws when the screen rotates. The card is `24` rem tall by default. Set `height` (a number of rem, a spacing token or a percentage, as on Flex) to change it. The header and legend take their own height and the plot takes the rest.

## Differences from the web

- Tapping a row shows the tooltip and the dots, instead of hovering.
- The legend sits above or below the plot, instead of over it.
- There is no date range picker. `date.selector`, `presets`, `dual`, `min`, `max` and `onChange` are not taken, and `date.format` knows the tokens listed above.
- There is no `DataThemeProvider`. `variant` is a prop (`gradient` by default), and `data-viz-style` sets the color mode per chart.
- The chart doesn't animate in, so `animation`, `animationBegin`, `animationDuration` and `animationEasing` are not taken.
- `reverseX` and `reverseY` are not taken. The x labels are always below and the y labels on the left.
- The `*Closed`, `*Open` and `*Y` curves draw as their plain form (`basisClosed` as `basis`, `monotoneY` as `monotone`).
- Rows without a value are joined over, instead of leaving a gap.
- The y labels take only the width they need, instead of a fixed 64px column. When x labels would overlap, only every second (or third, and so on) label is shown.
- Without `series`, only the keys that hold numbers become series.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `DataPoint[]` | | The rows. Each is an object with an x value and a number per series. |
| `series` | `SeriesConfig \| SeriesConfig[]` | | The keys to draw, each `{ key, color? }`. |
| `title` | `ReactNode` | | The heading above the plot. |
| `description` | `ReactNode` | | A line under the title. |
| `curve` | `CurveType` | `"natural"` | How the line runs between points. |
| `variant` | `"gradient" \| "flat" \| "outline"` | `"gradient"` | How the area under the line is filled. |
| `axis` | `"x" \| "y" \| "both" \| "none"` | `"both"` | Which axes show labels. |
| `grid` | `"x" \| "y" \| "both" \| "none"` | `"both"` | Which grid lines to draw. |
| `legend` | `{ display?, position?, direction? }` | `{ display: true, position: "top-left" }` | The legend's visibility, place and direction. |
| `tooltip` | `boolean` | `true` | Tap a row to show its values. |
| `xAxisType` | `"category" \| "number"` | `"category"` | Spread rows evenly, or place them by their x value. |
| `xDomain` | `[number, number]` | | The x range for `xAxisType="number"`. |
| `date` | `{ start?, end?, format? }` | | Filters date rows and formats date labels. |
| `loading` | `boolean` | `false` | Shows a spinner instead of the plot. |
| `error` | `boolean` | `false` | Shows `errorState` instead of the plot. |
| `emptyState` | `ReactNode` | `"No data available for the selected period"` | Shown when there are no rows. |
| `errorState` | `ReactNode` | `"An error occurred while fetching data"` | Shown when `error` is set. |
| `data-viz-style` | `"categorical" \| "divergent" \| "sequential"` | `"categorical"` | The color mode. `sequential` draws in brand shades. |
| `height` | `number \| SpacingToken \| "50%"` | `24` | The card's height, in rem as on Flex. |
| ...Flex props | `FlexProps` | | Margin, border, radius and the other Flex props. |
