`@once-ui-system/native` brings Once UI's basic components to iOS and Android apps built with React Native. They take the same props as the web components and read the same design tokens, so a screen written with Once UI looks and reads the same on a phone.

It is a preview. Most apps should keep shipping Once UI on phones as the web build wrapped in a native shell (the Stack mobile target); use this package when the app itself has to be native.

## Install

Needs React 19 and React Native 0.79 or later (Expo SDK 53 and up). Preview versions are published to the `next` tag.

codes={[
  {
    code: "npm install @once-ui-system/native@next",

## Usage

Wrap the app in `ThemeProvider`. It takes the same style options as on the web, with the same defaults; `theme="system"` follows the device.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { Button, Column, Heading, Text, ThemeProvider } from "@once-ui-system/native";

export default function App() {
  return (
    <ThemeProvider brand="orange" neutral="sand" solid="color">
      <Column padding="20" gap="12" background="page" fill>
        <Heading>Morning Coffee</Heading>
        <Text onBackground="neutral-weak">Three more coffees and the next one is on us.</Text>
        <Button label="Add stamp" onPress={() => {}} />
      </Column>
    </ThemeProvider>
  );
}`,
    language: "tsx",
    label: "App.tsx"
  }
]} />

## Components

| Component | Notes |
| --- | --- |
| `Flex`, `Row`, `Column` | Spacing, alignment, background, border, radius, shadow and sizes. `Flex` is a row, as on the web. |
| `Text`, `Heading` | `variant`, `onBackground`, `onSolid`, `truncate`. |
| `Button` | All ten variants, five sizes, `loading`, `disabled`, `fillWidth`. |
| `Card` | Pressable with `onPress` (or `onClick`), `selected`. |
| `Input`, `Textarea` | Floating label, error message, description, prefix and suffix, character count. |
| `Switch`, `Checkbox` | Controlled or not, with a label and description. |
| `Tag`, `Avatar`, `Feedback`, `Line`, `Spinner`, `Skeleton` | As on the web. |

`useTheme()` gives your own components the resolved tokens: `theme.color("brand-solid-strong")`, `theme.space("16")`, `theme.radius("l")`, `theme.text("heading-strong-m")`, `theme.shadow("m")`.

## Differences from the web

- **Icons.** `prefixIcon`, `suffixIcon` and `icon` take an element instead of an icon name, since the preview has no icon set yet.
- **Units.** Numbers on spacing and size props are rem, as on the web. Rem follows the screen size: 15pt on phones, 16pt on tablets.
- **Touch.** Pressed states replace hover, and small controls take taps from at least 44pt around them without being drawn larger.
- **Clipping.** `radius` does not clip children. Pass `overflow="hidden"` when it should; on iOS that also hides the view's shadow.
- **Responsive props** (`s`, `m`, `l`) are not supported yet. The phone breakpoint's token values apply on phones on their own.

## Design tokens

Both packages read one token export generated from the web package's SCSS tokens, so a token change reaches the web and native apps together. The same file ships as `@once-ui-system/core/tokens.json` for other tools, such as Figma or Swift and Kotlin code generators.
