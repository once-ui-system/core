`IconButton` is a square `Pressable` that shows one icon. It takes the same `variant` values as [Button](/native/components/button) and handles taps with `onPress`. See the [web IconButton page](/components/iconButton) for more on when to use it.

## Accessible name

An icon alone tells a screen reader nothing, so give every `IconButton` an `aria-label`. Without one, and without children, it logs a warning.

## Sizes and shape

`size` takes `xs` to `xl`, from 20 to 48 points square. `m` (32 points) is the default. Every size takes taps from a 44 point area. `rounded` makes it a circle.

<CodeBlock marginTop="8" marginBottom="24"
codes={[

export function Sizes() {
  return (
    <Row gap="8" vertical="center">
      <IconButton size="s" icon="plus" aria-label="Add" onPress={() => {}} />
      <IconButton size="m" icon="plus" aria-label="Add" onPress={() => {}} />
      <IconButton size="l" icon="plus" rounded aria-label="Add" onPress={() => {}} />

## Colour and custom content

The icon follows the variant. For an icon in a colour of its own, pass an `Icon` with `onBackground` as the children, as core 3.0 does for 2.x's `color`. Children replace the icon, for an element of your own.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { Icon, IconButton, Row, Text } from "@once-ui-system/native";

export function Custom() {
  return (
    <Row gap="8">
      <IconButton variant="ghost" aria-label="Like" onPress={() => {}}>
        <Icon name="heart" onBackground="danger-medium" />
      </IconButton>
      <IconButton variant="secondary" aria-label="Three items" onPress={() => {}}>
        <Text textVariant="label-strong-s">3</Text>
      </IconButton>
    </Row>
  );
}`,
    language: "tsx",
    label: "Custom.tsx"
  }
]} />

## Differences from the web

- **No tooltip.** There is no hover on a touch screen. `tooltip` is still accepted and becomes the accessible name when `aria-label` is not set.
- **`onPress`.** Taps go to `onPress`, as on any `Pressable`. There is no `onClick` or `href`.
- **Pressed, not hover.** The variant's pressed colours show while the finger is down.

## Props

`IconButton` also takes every React Native `Pressable` prop except `children` and `style`, which it replaces.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `icon` | `IconName` | `"refresh"` | The icon to show. |
| `aria-label` | `string` | | The accessible name. |
| `tooltip` | `string` | | Used as the accessible name when `aria-label` is not set. |
| `variant` | `ButtonVariant` | `"primary"` | Visual style, as on `Button`. |
| `size` | `"xs" \| "s" \| "m" \| "l" \| "xl"` | `"m"` | 20, 24, 32, 40 or 48 points square. |
| `rounded` | `boolean` | `false` | Makes the button a circle. |
| `loading` | `boolean` | `false` | Shows a spinner and blocks presses. |
| `disabled` | `boolean` | `false` | Greys the button out and blocks presses. |
| `children` | `ReactNode` | | Replaces the icon. |
| `onPress` | `(event) => void` | | Called on tap. |
| `style` | `ViewStyle` | | Applied after the button's own style. |
