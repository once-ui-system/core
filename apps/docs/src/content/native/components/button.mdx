`Button` renders a React Native `Pressable` with a label, optional icons and the same variants and sizes as the web. Handle taps with `onPress`. See the [web Button page](/components/button) for how each variant is meant to be used.

## Variants

`primary` is the default. `danger`, `success` and `warning` are solid like `primary`. `secondary`, `tertiary`, `quaternary`, `subtle`, `ghost` and `link` are quieter.

## Sizes and width

`size` takes `xs`, `s`, `m`, `l` and `xl`, from 24 to 56 points tall. `m` is the default. A button is as wide as its label; `fillWidth` stretches it to its parent, and `horizontal` aligns the content inside it.

<CodeBlock marginTop="8" marginBottom="24"
codes={[
  {
    code:
`import { Button, Column } from "@once-ui-system/native";

export function Sizes() {
  return (
    <Column gap="8" fillWidth>
      <Button size="s" label="Small" onPress={() => {}} />
      <Button size="l" label="Large" onPress={() => {}} />
      <Button size="l" fillWidth label="Continue" onPress={() => {}} />
      <Button
        variant="secondary"
        fillWidth
        horizontal="between"
        label="Payment method"
        suffixIcon="chevronRight"
        onPress={() => {}}
      />
    </Column>
  );
}`,
    language: "tsx",
    label: "Sizes.tsx"
  }
]} />

Small sizes still take taps from a 44 point area around them, without being drawn larger.

## Icons

`prefixIcon` and `suffixIcon` take a built-in icon name, as on the web, or any element. The icon takes the label's colour.

  return (

## States

`loading` swaps the prefix icon for a spinner and blocks presses. `disabled` greys the button out and blocks presses. Both are reported to screen readers.

## Differences from the web

- **`onPress`.** `Button` takes React Native's `Pressable` props, so taps go to `onPress`. There is no `onClick`.
- **No `href`.** A button does not render a link. Navigate in `onPress`, for example with your router.
- **Pressed, not hover.** Each variant shows its pressed colours while the finger is down.
- **No `arrowIcon`.** Use `suffixIcon="arrowRight"` for an arrow.

## Props

`Button` also takes every React Native `Pressable` prop except `children` and `style`, which it replaces.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | | The button's text. |
| `children` | `ReactNode` | | Used as the label when `label` is not set. |
| `variant` | `"primary" \| "secondary" \| "tertiary" \| "quaternary" \| "subtle" \| "danger" \| "success" \| "warning" \| "ghost" \| "link"` | `"primary"` | Visual style. |
| `size` | `"xs" \| "s" \| "m" \| "l" \| "xl"` | `"m"` | Height and padding. |
| `weight` | `"default" \| "strong"` | `"strong"` | Label weight. |
| `rounded` | `boolean` | | Fully rounded corners. |
| `prefixIcon` | `IconName \| ReactNode` | | Icon before the label. |
| `suffixIcon` | `IconName \| ReactNode` | | Icon after the label. |
| `loading` | `boolean` | `false` | Shows a spinner and blocks presses. |
| `disabled` | `boolean` | `false` | Greys the button out and blocks presses. |
| `fillWidth` | `boolean` | `false` | Stretches to the parent's width. |
| `horizontal` | `"start" \| "center" \| "end" \| "between"` | `"center"` | Content alignment inside the button. |
| `onPress` | `(event) => void` | | Called on tap. |
| `style` | `ViewStyle` | | Applied after the button's own style. |
