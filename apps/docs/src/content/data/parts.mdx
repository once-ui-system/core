When none of the charts fits, such as a calendar heatmap, a funnel or a map with values, build the visual yourself and give it the same frame as the charts. These parts are what every chart uses, so a custom visual next to a `LineChart` reads as one system.

```tsx
import { ChartHeader, ChartStatus, ChartSummary, Swatch } from "@once-ui-system/core/data";
import { useDataTheme } from "@once-ui-system/core";
```

The title, description and date-range picker on top of every chart. It renders nothing when it has neither a title, a description nor a selector.

## ChartStatus

The loading spinner, the error message or the empty message, centred in whatever box it sits in. Loading wins over an error, and an error over empty. It renders nothing when none is set.

```tsx
<Column fillWidth height="16rem">
  <ChartStatus loading={isLoading} error={Boolean(error)} empty={rows.length === 0} />
  {!isLoading && !error && rows.length > 0 && <Heatmap rows={rows} />}
</Column>
```

## ChartSummary

The hidden table every chart carries for screen readers: the x values as rows, a column per series, every value in the chart's format. Give a custom visual the same, from the same rows, so its numbers are reachable without sight.

```tsx
<figure aria-label="Bookings per hour">
  <Heatmap rows={rows} />
  <ChartSummary
    title="Bookings per hour"
    data={rows}
    xKey="hour"
    series={[{ key: "mon", label: "Monday" }, { key: "tue", label: "Tuesday" }]}
    valueFormat="number"
  />
</figure>
```

## Swatch

The colour sample in legends and tooltips, in the chart variant's fill.

```tsx
<Row vertical="center" gap="8">
  <Swatch color="var(--data-emerald)" />
  <Text textVariant="label-default-s">Booked</Text>
</Row>
```

`color` is a CSS colour as written: use `var(--data-emerald)` for a palette hue, since a bare `"emerald"` is the CSS named colour here. `size` is `"s"` or `"m"`, and `variant` defaults to the app's chart variant.

## useDataTheme

The chart settings from `DataThemeProvider`, the `dataStyle` section of your config, and a setter:

```tsx
const { variant, mode, height, axis, tick, setChartOptions } = useDataTheme();
```

Read `axis.stroke` and `tick.fill` to draw your own axes in the charts' colours, and `height` to match their size. `setChartOptions({ mode: "divergent" })` changes every chart under the provider; see [Recipes](/data/recipes#theme-switch-for-charts).
