`DivergingBars` draws one row per row of `data`: its name, a bar from zero, and its value. Gains grow right in the gain colour and losses left in the loss colour, all on one scale, so lengths compare across the list. Zero sits where the largest loss ends: a list with no losses uses the whole width. Every value is written with its sign (`+12%`), so colour is never the only cue. It takes the card, `title`, `description`, `valueFormat`, `locale`, `tooltip`, `loading`, `error`, `emptyState` and `errorState` the other charts take.

Bars are drawn in the order given, so sort the rows first to rank them. `dataKey` and `nameKey` read other keys than `"value"` and `"label"`. Gains are emerald and losses orange by default; `gainColor` and `lossColor` take any palette name or CSS colour.
