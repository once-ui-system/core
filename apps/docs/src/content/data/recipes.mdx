## Fetch in a server component

The charts render on the server, so the page can query and pass the rows straight in. The first HTML holds the drawn chart, with no loading spinner and no client fetch.

```tsx
// app/(dashboard)/revenue/page.tsx
import { LineChart } from "@once-ui-system/core/data";
import { getMonthlyRevenue } from "@/lib/reports";

export default async function RevenuePage() {
  const rows = await getMonthlyRevenue(); // [{ month: "2026-01-01", revenue: 32000 }, …]

  return (
    <LineChart
      title="Revenue"
      xKey="month"
      date={{ format: "MMM yyyy" }}
      valueFormat={{ style: "currency", currency: "EUR", maximumFractionDigits: 0 }}
      series={{ key: "revenue", label: "Revenue" }}
      data={rows}
    />
  );
}
```

Rows cross to the client as JSON, so send what the chart draws, not whole database records. `Date` values arrive as `Date`s; numbers stored as strings (Postgres `numeric`) need a `Number()` first. Keep function props out of server components: see [Numbers and dates](/data/formatting#from-a-server-component).

## This period against the last

Draw the comparison as a quiet reference: last period in `gray`, this period in a colour.

<LineChart

  marginBottom="24"

  legend={{ position: "top-right" }}
  curve="linear"
  xKey="day"
  series={[

    { key: "current", label: "This month", color: "brand" }

    { day: "1", previous: 40, current: 48 },
    { day: "5", previous: 46, current: 55 },
    { day: "10", previous: 52, current: 61 },
    { day: "15", previous: 49, current: 70 },
    { day: "20", previous: 58, current: 74 },
    { day: "25", previous: 61 },
    { day: "30", previous: 64 }

/>

Align the two periods by position (day 1, day 2…), not by date, so they share the axis. The current period stops where today is: leave its later values out instead of writing `0`, and the line ends there.

```ts
const data = lastMonth.map((row, i) => ({
  day: String(i + 1),
  previous: row.signups,
  current: thisMonth[i]?.signups, // undefined after today: a gap, not a zero
}));
```

## Top N and other

A pie past five slices stops being readable. Keep the biggest and add up the rest:

```ts
function topN<T extends { name: string; value: number }>(rows: T[], n = 4) {
  const sorted = [...rows].sort((a, b) => b.value - a.value);
  const rest = sorted.slice(n).reduce((sum, row) => sum + row.value, 0);
  return rest > 0
    ? [...sorted.slice(0, n), { name: "Other", value: rest, color: "gray" }]
    : sorted;
}
```

<PieChart
  marginTop="16"
  marginBottom="24"
  title="Traffic by source"
  height="20rem"
  ring={{ inner: 55, outer: 70 }}
  legend={{ display: true, position: "top-left", direction: "column" }}
  valueFormat="compact"
  series={{ key: "value", label: "Sessions" }}
  data={[
    { name: "Search", value: 42100 },
    { name: "Direct", value: 31800 },
    { name: "Social", value: 12400 },
    { name: "Email", value: 8300 },
    { name: "Other", value: 5900, color: "gray" }
  ]}
/>

`gray` marks "Other" as the leftovers, not a fifth source to compare.

## Target and actual

[`LineBarChart`](/data/lineBarChart) draws its first series as a line and its second as bars, on one axis: the target as the line, the actuals as bars.

```tsx
<LineBarChart
  title="Spend against budget"
  xKey="month"
  valueFormat={{ style: "currency", currency: "EUR", notation: "compact" }}
  series={[
    { key: "budget", label: "Budget", color: "gray" },
    { key: "spend", label: "Spend", color: "brand" },
  ]}
  data={rows}
/>
```

## Live data

For a chart that updates every second, keep the x range fixed so the axis doesn't rescale on each sample. [`useStreamingViewport`](/hooks/useStreamingViewport) buffers the samples and pans the visible window; the live examples on [LineChart](/data/lineChart#live-data) show it with the animation tuned to glide, and turned off to snap.

```tsx
<LineChart
  animation={false}
  xAxisType="number"
  xDomain={[now - 60_000, now]}
  xKey="t"
  series={{ key: "rps", label: "Requests/s" }}
  data={samples}
/>
```

## Let the reader switch views

`LineChart` and `BarChart` take the same props, so one set of props can draw either. A `SegmentedControl` picks which.

```tsx
"use client";

import { useState } from "react";
import { Column, SegmentedControl } from "@once-ui-system/core";
import { BarChart, LineChart } from "@once-ui-system/core/data";

export function OrdersChart({ data }: { data: { month: string; web: number; store: number }[] }) {
  const [view, setView] = useState("line");
  const props = {
    title: "Orders",
    xKey: "month" as const,
    series: [
      { key: "web" as const, label: "Web" },
      { key: "store" as const, label: "Store" },
    ],
    data,
  };

  return (
    <Column gap="12">
      <SegmentedControl
        buttons={[
          { value: "line", label: "Trend" },
          { value: "bar", label: "Compare" },
        ]}
        value={view}
        onValueChange={setView}
      />
      {view === "line" ? <LineChart {...props} /> : <BarChart {...props} />}
    </Column>
  );
}
```

## Theme switch for charts

`useDataTheme()` reads the chart settings and `setChartOptions` changes them for every chart under the provider. A new `mode` is also remembered in the browser.

```tsx
"use client";

import { SegmentedControl, useDataTheme } from "@once-ui-system/core";

export function ChartModeSwitch() {
  const { mode, setChartOptions } = useDataTheme();
  return (
    <SegmentedControl
      buttons={[
        { value: "categorical", label: "Categorical" },
        { value: "divergent", label: "Divergent" },
        { value: "sequential", label: "Sequential" },
      ]}
      value={mode}
      onValueChange={(value) => setChartOptions({ mode: value as typeof mode })}
    />
  );
}
```
