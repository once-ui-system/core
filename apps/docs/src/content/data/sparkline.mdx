`Sparkline` draws the shape of a series in the space of a line of text. It has no axes, legend, tooltip or card, and no recharts behind it: it is one SVG, so it renders in a server component and costs no JavaScript. The drawing stretches to its box (`preserveAspectRatio="none"`) while the line keeps its width, so it fills a table cell or a tile at any size.

It fills its container's width and is 32px tall unless `width` and `height` say otherwise. A number is px; any CSS length, such as `"100%"` or `"2rem"`, passes through. It also ships from the package root, as it pulls in nothing the root does not already have.

## Bars

`variant="bar"` draws one bar per value, from zero, so negative values hang below the line. With `showLast` the latest bar is in full colour and the rest are dimmed.

## Curves and range

`curve` joins the points: `"monotone"` (the default, smooth and never past a point), `"natural"` (the charts' spline), `"linear"` or `"step"`. `min` and `max` fix the values at the bottom and top edges, so sparklines side by side share a scale instead of each filling its own height.

## Rows of data

Pass your rows as they are and name the key to plot with `valueKey`. Without it, the first key holding a number is used.

```tsx
const week = [
  { day: "Mon", signups: 31 },
  { day: "Tue", signups: 44 },
  { day: "Wed", signups: 38 },
];

<Sparkline data={week} valueKey="signups" />
```

## Accessibility

A sparkline is one image to a screen reader (`role="img"`). Without an `aria-label` it is named by a summary of its values, written in `valueFormat` and `locale`: the first example above reads "Trend from 120 to 340, high 360". Pass `aria-label` when the tile around it does not already say what the line is, such as "Revenue, last 8 weeks".
