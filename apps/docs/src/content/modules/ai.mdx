Use these where an assistant is doing something the person is waiting on. Every piece takes the
brand color, so inside a themed chat it follows the chat's theme, and every piece keeps saying
"working" under reduced motion without moving.

## WorkingIndicator

A moving mark and a verb that changes every few seconds, like "Imagining…" or "Noodling…". The
first render always shows the first verb, so server and client agree; the order shuffles after
mount.

### Your own words

Pass `verbs` to give a product its own voice, or spread `workingVerbs` to add to the default list.
`label` shows one fixed line instead, for a step you can name.

      language: "tsx",

### Elapsed time and a hint

`showElapsed` counts seconds since `startedAt` (or since the indicator appeared), and `detail` adds
a quiet hint after it.

## VoiceVisualizer

The animation for a voice conversation. Each state moves differently: idle breathes, listening
ripples, thinking swirls and speaking pulses like syllables. Give it the microphone stream while
listening and the reply's `<audio>` element while speaking, and it follows the real sound. Use
`orb` for a full-screen voice mode and `bars` for a composer or a call bar.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <VoiceStatesExample />
  }
  codes={[
    {
      code:
`const [stream, setStream] = useState<MediaStream | null>(null);

<VoiceVisualizer state="listening" source={stream} />
<VoiceVisualizer variant="bars" state="speaking" source={replyAudioElement} />`,
      language: "tsx",
      label: "Audio"
    },
    {
      code:
`<VoiceVisualizer state={state} level={levelFromYourSdk} />`,
      language: "tsx",
      label: "Level"
    }
  ]}
/>

Levels are written straight to CSS variables every frame, so a live microphone never re-renders
React. When your voice SDK already gives you a loudness number, pass it as `level` instead. To drive
something of your own, `useAudioLevel(source)` returns the same loudness from 0 to 1.

## Mascot

A companion for an assistant: a character with a face that idles, listens, thinks, speaks and
sleeps, with a mood on top. Its eyes follow the pointer, and while speaking its mouth opens with the
reply's audio. The default body is the Once UI mark with a face; `orb` and `squircle` are softer.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <MascotStatesExample />
  }
  codes={[
    {
      code:
`<Mascot state="thinking" />
<Mascot state="listening" mood="happy" shape="orb" eyes="pill" />
<Mascot state="speaking" source={replyAudioElement} shape="squircle" eyes="visor" accessory="antenna" />`,
      language: "tsx",
      label: "States"
    }
  ]}
/>

### Make it yours

Shape, eyes, accessory and cheeks are props, and the body takes the brand hue, so a chat theme
recolors it. `palette` sets any part to your own colors; from CSS, the same parts are the
`--mascot-body`, `--mascot-body-deep`, `--mascot-ink`, `--mascot-sclera`, `--mascot-cheek`,
`--mascot-glow` and `--mascot-halo` variables.

## LogoSpinner

The four tiles of the Once UI mark, moving. `twist` parts the tiles, turns a quarter and clicks
them back; `wave` lifts one tile at a time. Keep `Spinner` for buttons and fields, and use this one
where the product's own loader belongs.

## Accessibility

`WorkingIndicator` is one `status` region with a fixed name, "Working" unless you pass `ariaLabel`,
so a screen reader announces it once instead of reading every new verb. With reduced motion the
tiles stop moving and fade in turn, the verbs swap without sliding and the shimmer is off.

`VoiceVisualizer` is a `status` region that announces its state ("Listening", "Speaking"). With
reduced motion its stand-in animations stop; real audio still shows, as glow on the orb and as bar
height, because that is feedback the person needs while they talk.

`Mascot` is one image named for what it is doing ("Assistant, thinking"). With reduced motion it
holds still and keeps its poses and expressions; it does not blink, bob or talk on its own.
