Five components cover the parts every chat has: `ChatMessage`, `ChatMessageList`, `ChatComposer`, `TypingIndicator` and `ConversationItem`. They work for conversations between people and for an assistant that streams its replies.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={<ChatConversationExample />}
  codes={[
    {
      code:
`import {
  ChatComposer,
  ChatMessage,
  ChatMessageList,
  Column,
  TypingIndicator,
} from "@once-ui-system/core";

<Column fillWidth height={28}>
  <ChatMessageList ariaLabel="Chat with Lorant" stack>
    {messages.map((message) => (
      <ChatMessage
        key={message.id}
        from={message.from}
        name={message.from === "other" ? "Lorant" : undefined}

        time={message.time}
        status={message.from === "self" ? "read" : undefined}
      >
        {message.text}
      </ChatMessage>
    ))}
    {typing && <TypingIndicator ariaLabel="Lorant is typing" marginLeft="48" />}
  </ChatMessageList>
  <ChatComposer onSend={({ text, files }) => send(text, files)} attach />
</Column>`,
      language: "tsx",
      label: "Conversation"
    }
  ]}
/>

## ChatMessage

One message: the bubble, its author, the time and the delivery state. `from="self"` puts it on the right with the brand tint. Set `grouped` on a follow-up from the same author: the name is dropped and the avatar keeps its space, so the bubbles line up. A `Date` in `time` is formatted for the reader and rendered as a `<time>` element: the time of day by default, or with `timeFormat="relative"` a short distance from now ("now", "2m", "1h", then the date) in the reader's language that keeps itself current, with the full time on hover.

The same wording is exported as `formatRelativeTime(date, { style, locale })` for anything else that labels a time: `"narrow"` (the default) gives "now", "2m", "1h", "3d", "2w" and then the date; `"short"` and `"long"` give "5 min. ago" and "5 minutes ago". It uses the platform's `Intl`, so every locale reads in its own words with nothing to translate.

`variant="plain"` drops the bubble for a flat, team-chat layout where every message reads left to right. `attachments` takes media or link previews under the text, `footer` takes reactions, and `actions` takes controls that show while the message is hovered or focused (they are always shown on touch screens).

## ChatMessageList

The scrolling column a conversation lives in. It starts at the newest message and follows new ones, including content that grows on its own like a streamed reply, while the reader is at the bottom. Once they scroll up to read history it stays where they are. `onReachStart` fires when they reach the top, to load older messages. The list is a `log` live region, so screen readers announce new messages.

Give it a parent with a fixed or flexible height; it fills the space and scrolls inside it.

`stack` draws a quick run of messages from one author as one block: the bubbles close up and round less where they meet, the name and avatar show once, and the time and delivery state show under the last message. Messages stack when they sit next to each other with the same `from`, `name` and `variant`, sent within `stackWithin` minutes (5 by default) of each other. There is nothing to compute per message; the conversation at the top of this page uses it.

## ChatComposer

The input bar. The field grows with the draft up to about eight lines, Enter sends and Shift+Enter starts a new line (an Enter that confirms an IME composition never sends). `onSend` gets the trimmed text and the attached files. If it returns a promise the send button shows loading; the field clears when the promise resolves and keeps the draft when it rejects, so showing the error is up to you.

`attach` adds a button that opens the file picker. Pasted images are attached too. Picked images show as thumbnails, other files as chips with their name; each has a remove button. Pass `{ accept, multiple }` to limit what can be picked.

### Toolbar

`toolbar` adds a row under the field for chips, a model picker or other controls, and `hint` puts quiet text such as "Enter to send" before the send button. With either one, the attach button moves to the start of that row, and `actions` and send to its end. `sendIcon` swaps the send button's icon. Without them the composer stays one row.

## ConversationItem

One row of an inbox: the avatar, the name, the last message and its time, and an unread count. It is a button with `onClick` and a link with `href`, and `selected` marks the open conversation with `aria-current`. A `Date` in `time` shows the time today, the weekday this week and the date before that.

  marginBottom="24"
