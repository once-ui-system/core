`ElementType` is internal in Once UI 3.0. It is the element `Button`, `IconButton`, `ToggleButton` and `SmartLink` render as a link when they get an `href` and as a button otherwise, through the framework adapter, and it is no longer exported from `@once-ui-system/core`.

Use the component for the job instead:

- A link: [`SmartLink`](/components/smartLink), which routes internal links through your framework's link.
- An action: [`Button`](/components/button) or [`IconButton`](/components/iconButton), which become links when given an `href`.
- A bare clickable box: a plain `<a>` or `<button>` with a `Flex` inside it.

See [Migrating from 2.x](https://github.com/once-ui-system/core/blob/main/MIGRATING.md) for the full list of exports that became internal.
