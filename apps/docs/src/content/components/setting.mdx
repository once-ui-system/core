Every editor UI grows the same row: a label, sometimes a description, sometimes
an explainer, and one control on the right. `Setting` is that row.

The control is passed as **children** rather than as a typed prop, so the
component never has to know what can sit in it — including controls that do not
exist yet.

## Info

`info` puts a sentence of context behind a small icon beside the label, so a
setting can explain itself without spending a line of the panel on a description
that is only read once. It renders an `InfoTip`, which is also exported on its
own for use anywhere else.

## Groups

With `control` or `open`, a Setting becomes a group (2.x's `SettingGroup`): it nests sub-settings **inside** its own box rather than beside it,
so the relationship survives a panel with ten groups in it. The header control
is what usually gates the body; `open` shows or hides it.

The group is a single surface — the header and the body it reveals share one
background, separated by a hairline — so opening one grows the panel instead of
stacking a second panel inside it. Its border is an alpha, which reads against
whatever the group is nested in.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  previewPadding="24"
  preview={<SettingGroupExample />}
  codes={[
    {
      code:
`<Setting
  label="Watermark"
  control={<Switch checked={enabled} onCheckedChange={toggleEnabled} />}
  open={enabled}
>
    <Setting label="Opacity">
      <Slider value={opacity} onValueChange={setOpacity} />
    </Setting>
    <Setting label="Position">
      <SegmentedControl value={position} onValueChange={setPosition} buttons={positions} />
    </Setting>
</Setting>`,
      language: "tsx",
      label: "Group"
    }
  ]}
/>

## Axes

A property with more than one axis belongs in one row. `axes` (2.x's `SettingAxes`) puts them
side by side, and wraps when the panel is too narrow, instead of splitting into
two rows that read as unrelated settings.

  marginTop="16"
  marginBottom="24"

  label="Tilt"

    { label: "Y", control: <Slider value={y} min={-45} max={45} onValueChange={setY} /> },
  ]}
/>`,

    }
  ]}
