`Badge` folded into [Tag](/components/tag) in Once UI 3.0 and is no longer exported. Its look is `<Tag variant="announce">`, with `href`, `arrow` and `effect` as before:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Row gap="16" center>
      <Tag variant="announce" label="New release" prefixIcon="rocket" href="#" />
    </Row>
  }
  codes={[
    {
      code:
`// 2.x
<Tag variant="announce" label="New release" prefixIcon="rocket" href="/changelog" />

// 3.0
<Tag variant="announce" label="New release" prefixIcon="rocket" href="/changelog" />`,
      language: "tsx",
      label: "Badge → Tag"
    }
  ]}
/>

`title` is `label` and `icon` is `prefixIcon`. Each arrow now follows hover on its own tag, so the `id` 2.x needed on every badge of a page can go. The 3.0 codemod rewrites the element, its import and its props. See [Tag: Announcement](/components/tag#announcement).
