`StatTile` shows one number with its label and context. A row of them sits at the top of a dashboard or a console, with the figures people check first. It is one of the control-room pieces added in 3.0.

## A row of tiles

A tile fills the width it is given, so lay several out in a `Grid` or a wrapping `Row`. Pass `value` already formatted for the reader's locale, such as `"1,284"`, `"€12.4k"` or `"94%"`. The tile draws it with tabular figures, so numbers in neighbouring tiles line up.

## Delta

`delta` shows the change since the last period beside the value. Its `label` is the text, such as `"+12%"` or `"−3 since Monday"`. `direction` draws an up or down arrow, and leaving it out draws none. `tone` colours it: `success`, `danger`, `warning` or `neutral` (the default).

Direction and tone are separate on purpose. A number going down can be good news, such as fewer failed payments, so set the tone by what the change means, not by which way it went.

`chart` takes a small chart that sits under the value, usually a `Sparkline` from `@once-ui-system/core/data`.

## Link and loading

With `href`, the whole tile is a link to the screen it sums up, drawn as a `Card`. Without `href` it is a plain panel and does not look clickable.

`loading` draws a placeholder in place of the value and hides the delta, so the tile keeps its size while the number loads.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Grid fillWidth columns="2" s={{ columns: "1" }} gap="12">
      <StatTile label="Unpaid invoices" value="7" icon="document" hint="Open the invoice list" href="#link-and-loading" />
      <StatTile label="Orders today" value="" icon="cart" loading />
    </Grid>
  }
  codes={[
    {
      code:
`<StatTile label="Unpaid invoices" value="7" icon="document" hint="Open the invoice list" href="/invoices?status=unpaid" />
<StatTile label="Orders today" value={orders?.length} icon="cart" loading={!orders} />`,
      language: "tsx",
      label: "Link and loading"
    }
  ]}
/>

## Accessibility

- The label, value, delta and hint are text, read in that order. The delta's arrow is hidden from screen readers, so write the direction into `delta.label` with a sign, such as `"+12%"` or `"−3"`, and do not rely on colour alone.
- With `href` the tile is one link, and its name is all the text inside it. Keep the label short so the link reads well.
- While `loading`, the placeholder is labelled "Loading".

## API reference

StatTile also takes the layout and style props of `Column` (`padding`, `radius`, `background`, `border` and the rest), except `children`. With `href`, they go to the `Card` that draws the tile.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `ReactNode` | required | What is counted, such as "Open jobs" or "Revenue this week". |
| `value` | `ReactNode` | required | The number, already formatted for the locale. |
| `icon` | `IconName` | | An icon beside the label. |
| `hint` | `ReactNode` | | A line of context under the value, such as "of 1,500 seats". |
| `delta` | `StatTileDelta` | | The change since the last period, beside the value. |
| `chart` | `ReactNode` | | A small chart under the value, such as a `Sparkline`. |
| `href` | `string` | | Makes the whole tile a link. |
| `loading` | `boolean` | `false` | Draws a placeholder for the value while it loads. |

### StatTileDelta

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | required | The change, such as `"+12%"`. |
| `direction` | `"up" \| "down"` | | Draws an arrow. Left out, no arrow. |
| `tone` | `"success" \| "danger" \| "warning" \| "neutral"` | `"neutral"` | Whether the change is good news, separate from its direction. |
