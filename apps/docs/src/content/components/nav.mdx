Every product built on Once UI grew its own sidebar, and they all converged on
the same two rows: a link that knows whether it is the current page, and a
collapsible group of those links indented behind a rail. These are those two.

They are rows, not a sidebar. Headers, footers, org switchers and storage meters
differ per product and stay yours to compose.

      language: "tsx",

The rail is a vertical `Line`, not padding — indentation alone stops reading as
hierarchy the moment a label wraps. A group manages its own open state unless
you pass `open` and `onToggle`, which is what you do to open the group holding
the current route.

## Which row is current

This is the part worth taking from here rather than writing again.

`pathname === href` misses a nested route: on `/settings/billing/invoices/42`
nothing is highlighted. `pathname.startsWith(href)` overshoots the other way:
`/settings` is a prefix of every child, so the parent lights up alongside them.
The answer is the **longest** href that matches.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codes={[
    {
      code:
`import { selectNavHref } from "@once-ui-system/core";

const items = [
    { href: "/settings", label: "General" },
    { href: "/settings/billing", label: "Billing" },
];

const current = selectNavHref(pathname, items.map((i) => i.href));

{items.map((item) => (
    <NavItem key={item.href} {...item} selected={item.href === current} />
))}`,
      language: "tsx",
      label: "selectNavHref"
    }
  ]}
/>

It returns `null` when nothing matches, and will not match a sibling that merely
shares a prefix — `/settings-v2` is not inside `/settings`.
