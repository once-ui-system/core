The `OgCard` component displays rich link previews for URLs by fetching and rendering Open Graph metadata. It's perfect for showcasing external links with preview images, titles, and descriptions.

  marginTop="16"
  marginBottom="24"

      url="https://once-ui.com"
    />
  }
  codes={[
    {
      language: "tsx",

      code:
`<OgCard 
    url="https://once-ui.com"
/>`,
    }
  ]}
/>

## Required API routes

To use `OgCard` with automatic Open Graph fetching, your application must expose two routes: one that fetches a page's metadata, and one that serves its image from your origin. In a Next.js app, both are ready-made in `@once-ui-system/core/next`, with SSRF protection built in:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  lineNumbers
  codes={[
    {
      code:
`import { createOgFetchRoute } from "@once-ui-system/core/next";

export const { GET } = createOgFetchRoute();`,
      language: "tsx",
      label: "app/api/og/fetch/route.ts"
    },
    {
      code:
`import { createOgProxyRoute } from "@once-ui-system/core/next";

export const { GET } = createOgProxyRoute();`,
      language: "tsx",
      label: "app/api/og/proxy/route.ts"
    }
  ]}
/>

See [OG route handlers](/utils/ogRoutes) for their options. Outside Next.js, build the routes on [`handleOGFetch`](/utils/handleOGFetch) and [`handleOGProxy`](/utils/handleOGProxy).

`OgCard` calls `/api/og/fetch` and `/api/og/proxy` by default. If your routes live elsewhere, wrap the app in `OgRoutesProvider`:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  lineNumbers
  codes={[
    {
      code:
`<OgRoutesProvider routes={{ fetch: "/og/fetch", proxy: "/og/proxy" }}>
  {children}
</OgRoutesProvider>`,
      language: "tsx",
      label: "Custom routes"
    }
  ]}
/>

The optional `/api/og/generate` route renders social images for `Meta.generate`; it is not needed by `OgCard`.

## Service configuration

Use `serviceConfig` to point a single `OgCard` at custom API routes (it takes precedence over `OgRoutesProvider`) or to transform proxied image and favicon URLs. Pass pre-fetched data with `ogData` to skip the fetch entirely.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codeHeight={24}
  lineNumbers
  codes={[
    {
      code:
`<OgCard
  url="https://example.com"
  serviceConfig={{
    fetchOgUrl: '/api/og/fetch',
    proxyOgUrl: '/api/og/proxy',
    proxyImageUrl: (url) => \`/api/og/proxy?url=\${encodeURIComponent(url)}\`,
    proxyFaviconUrl: (url) => \`/api/og/proxy?url=\${encodeURIComponent(url)}\`,
  }}
/>

<OgCard
  ogData={{
    url: 'https://example.com',
    title: 'Example',
    description: 'Pre-fetched metadata',
    image: 'https://example.com/og.png',
    faviconUrl: 'https://example.com/favicon.ico',
  }}
/>`,
      language: "tsx",
      label: "Service configuration"
    }
  ]}
/>

## Notes

- The component automatically fetches favicons for the domain
- Images are proxied through an API endpoint to avoid CORS issues
- You can overwrite the default props by providing static values
- You can set any value to `false` to disable it
