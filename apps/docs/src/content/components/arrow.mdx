A decorative arrow, the cue on a card or link that the whole surface goes somewhere. It is the built-in `arrowRight` icon: its head rests as a chevron, and while the link, button or `data-arrow-trigger` element around it is hovered or keyboard-focused, the shaft grows in and the head moves forward. CSS only, with the [icon motion](/components/icon#motion) timing for the theme's border shape. `Button` (`arrowIcon`) and `Tag` (`arrow`) draw the same arrow themselves; use `Arrow` on its own for anything else, such as a whole-card link or a hover card.

## On a card

A card with `href` is a link, so the arrow follows it with nothing to wire. The arrow takes Flex's layout props, so `position`, `top` and `right` pin it to a corner (a number is on the token scale, as the spacing step of the same name is).

## Usage notes

- The arrow follows the closest link, button, `role="button"`/`"link"` or `data-arrow-trigger` element around it, on hover and on keyboard focus. Pass `trigger` (a CSS selector, on the page when the arrow mounts) only for an element elsewhere; that path follows the pointer alone.
- The arrow is decorative and hidden from assistive technology; the trigger element carries the link or action.
- For a button or a tag, use `Button arrowIcon` or `Tag arrow`.
- Under `prefers-reduced-motion`, or a theme with micro transitions off, it stays a chevron and the shaft appears without moving.
