A decorative arrow that animates in while a trigger element is hovered: the cue on a card or link that the whole surface goes somewhere. `Button` (`arrowIcon`) and `Tag` (`arrow`) draw the same arrow themselves; use `Arrow` on its own for anything else, such as a whole-card link or a hover card.

## On a card

Give the card an `id` and point `trigger` at it. The arrow takes Flex's layout props, so `position`, `top` and `right` pin it to a corner (a number is on the token scale, as the spacing step of the same name is).

## Usage notes

- `trigger` must be a valid CSS selector (`#element-id`, `[data-card="pro"]`), and the element must be on the page when the arrow mounts.
- The arrow is decorative and hidden from assistive technology; the trigger element carries the link or action.
- For a button or a tag, use `Button arrowIcon` or `Tag arrow`, which wire the hover for you.
