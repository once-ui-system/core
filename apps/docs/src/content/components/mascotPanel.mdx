`MascotPanel` lets people design their own [Mascot](/modules/ai#mascot). It edits a `MascotDesign`, a plain JSON value your app stores (a database column, a URL, local storage) and spreads back onto `<Mascot />` with `mascotDesignProps`. It comes from `@once-ui-system/blocks`, next to StylePanel, and works the same way.

## Storing a design

`MascotDesign` holds no React nodes or functions, so it fits a jsonb column as it is. Read every stored or AI-written design through `parseMascotDesign`: it never throws, drops what it does not know, clamps numbers to their range and only keeps colors and paths that look like colors and paths.

```tsx
import { Mascot, mascotDesignProps, parseMascotDesign } from "@once-ui-system/core";

const design = parseMascotDesign(agent.look);

<Mascot {...mascotDesignProps(design)} state="thinking" size="m" />
```

Without `value` the panel keeps its own state from `defaultValue`, and with `storageKey` it remembers it in the browser.

## What it edits

- **Body:** color (brand, accent, neutral or your own), roundness, width and surface.
- **Eyes:** shape, size, spacing, height and an optional color.
- **Face:** mouth, brows and cheeks.
- **Accessories:** the nine built-ins as tiles, several at once, and one optional color.
- **Working:** what it turns into while it thinks: nothing, the `cube` or the `d20`, with its sides and face.
- **Motion:** its personality.

The preview tries every state and mood, kawaii ones included. That part is never saved.

## Exports

The actions under the preview are free: Randomize, Reset, Copy JSON, Copy JSX, and the flat mascot as an SVG or PNG file, drawn in the browser. Pass `exports` to add your own buttons after them; they read the design with `useMascotPanel()`.

```tsx
function GifButton() {
  const { value } = useMascotPanel();
  return <Button size="s" variant="tertiary" onClick={() => makeGif(value)}>GIF</Button>;
}

<MascotPanel exports={<GifButton />} />
```

## Compose your own

Like StylePanel, the panel is a plain composition of its parts. Use `MascotPanelRoot` with only the sections you need, and hide single rows with `rows`:

```tsx
<MascotPanelRoot value={design} onValueChange={setDesign} stacked>
  <MascotPanelPreview rows={{ mood: false }} />
  <MascotPanelBody rows={{ aspect: false }} />
  <MascotPanelAccessories />
</MascotPanelRoot>
```

`visibility` does the same on the whole panel, `preview` moves the preview (`side`, `top` or `none`), and `labels` translates every string it shows or announces.
