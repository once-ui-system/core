Dialogs are overlay windows that focus user attention on important information, collect input, or require decisions. They appear above the main content and block interaction with the rest of the page until dismissed.

## Basic usage

A simple dialog with a title, description, and content.

<CodeBlock

    <BasicDialog />

return (
    <>
      <Button onClick={() => setIsOpen(true)}>
        Open Dialog
      </Button>
      <Dialog
        open={isOpen}
        onClose={() => setIsOpen(false)}

        description="This is a simple dialog with a title and description."

            <Input

              label="Enter your name"
            />
            <Button label="Submit" onClick={() => setIsOpen(false)}/>

        </Column>
      </Dialog>

## Stacked dialogs

Dialogs can be stacked on top of each other for multi-step interactions. Give the dialog on top `stack` and the one beneath `base`: the base dialog dims and turns inert until the stacked one closes. No provider is needed (2.x needed a `DialogProvider`; 3.0 removed it).

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <StackedDialogs />
  }
  codes={[
    {
      code:
`const [isBaseOpen, setIsBaseOpen] = useState(false);
const [isStackedOpen, setIsStackedOpen] = useState(false);

return (
    <>
      <Button variant="secondary" onClick={() => setIsBaseOpen(true)}>
        Open stacked dialogs
      </Button>
      
      <Dialog
        open={isBaseOpen}
        onClose={() => setIsBaseOpen(false)}
        title="Base dialog"
        base={isStackedOpen}
        footer={
          <Row gap="8">
            <Button variant="secondary" onClick={() => setIsBaseOpen(false)}>
              Close
            </Button>
            <Button onClick={() => setIsStackedOpen(true)}>
              Open stacked dialog
            </Button>
          </Row>
        }
      >
        <Text marginBottom="16">
          This is the base dialog. Click the button below to open a stacked dialog on top.
        </Text>
      </Dialog>
      
      <Dialog
        open={isStackedOpen}
        onClose={() => setIsStackedOpen(false)}
        title="Stacked dialog"
        stack
        footer={
          <Button onClick={() => setIsStackedOpen(false)}>Close stacked dialog</Button>
        }
      >
        <Text>
          This is a stacked dialog that appears on top of the base dialog.
          Notice how the base dialog is dimmed in the background.
        </Text>
      </Dialog>
    </>
);`,
      language: "tsx",
      label: "Stacked dialogs"
    }
  ]}
/>

## Accessibility

The Dialog component follows accessibility best practices:

- Uses `role="dialog"` and `aria-modal="true"`
- Traps focus within the dialog when open
- Supports keyboard navigation and Escape key to close
- Provides proper labeling with `aria-labelledby`
- Makes content outside the dialog inert when dialog is open

### Features

The sheet includes several built-in features:

- **Smooth animations**: Fade-in overlay with a slide-up sheet transition
- **Scroll lock**: Prevents body scrolling while the sheet is open
- **Keyboard navigation**: Press Escape to close
- **Click outside**: Click outside the sheet to dismiss
- **Auto-scroll reset**: Content scrolls to top when the sheet opens
- **Accessibility**: `role="dialog"` and `aria-modal="true"` on the overlay, focus kept inside by `FocusTrap` and returned to the trigger on close, the page behind inert

### Behavior

- The sheet slides up from the bottom with a 600ms ease transition
- Overlay fades in with a 300ms transition
- Close button is positioned in the top-right corner
- Content area is scrollable if it exceeds viewport height
- The sheet is rendered in a portal to `document.body`
