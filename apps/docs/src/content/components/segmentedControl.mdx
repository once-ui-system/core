Use this component for toggle-style selection between discrete options. It supports keyboard interaction, styling, and controlled or uncontrolled usage.

  marginTop="16"
  marginBottom="24"
  preview={
    <SegmentedControl
      fillWidth={false}
      buttons={[
        { value: "day", label: "Day" },
        { value: "week", label: "Week" },
        { value: "month", label: "Month" },
      ]}
    />
  }

## Radio group

A tab strip is the default, for switching views. For one choice among settings, `semantics="radio"` makes the segments a `radiogroup` of `radio`s: the arrow keys move and choose, as native radios do. Name it with `aria-label` or `aria-labelledby`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Row fillWidth horizontal="center">
      <SegmentedControl
        fillWidth={false}
        semantics="radio"
        aria-label="Density"
        defaultValue="comfortable"
        buttons={[
          { value: "compact", label: "Compact" },
          { value: "comfortable", label: "Comfortable" },
        ]}
      />
    </Row>
  }
  codes={[
    {
      code:
`<SegmentedControl
    fillWidth={false}
    semantics="radio"
    aria-label="Density"
    defaultValue="comfortable"
    buttons={[
      { value: "compact", label: "Compact" },
      { value: "comfortable", label: "Comfortable" },
    ]}
/>`,
      language: "tsx",
      label: "Radio group"
    }
  ]}
/>
