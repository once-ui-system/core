The Slider component provides an intuitive way to select a value from a range using a draggable thumb along a track.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <SliderBasicExample />
  }

    {
      code:
`const [value, setValue] = useState(50);

return (
    <Slider
      value={value}
      onChange={setValue}
      min={0}
      max={100}
    />
);`,
      language: "tsx",
      label: "Slider"
    }
  ]}
/>

## Uncontrolled

Without `value`, Slider keeps its own state and starts at `defaultValue`, or at
`min` when there is none. `onChange` is optional then: give the slider a `name` and
a form submits its value, or read it from a ref.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Slider label="Volume" name="volume" defaultValue={40} showValue />
  }
  codes={[
    {
      code:
`<Slider label="Volume" name="volume" defaultValue={40} showValue />`,
      language: "tsx",
      label: "Uncontrolled"
    }
  ]}
/>

For two thumbs that select a range, use [`RangeSlider`](/components/rangeSlider).
