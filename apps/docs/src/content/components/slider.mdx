The Slider component provides an intuitive way to select a value from a range using a draggable thumb along a track.

return (
    <Slider
      value={value}
      onValueChange={setValue}
      min={0}
      max={100}
    />
);`,

## Uncontrolled

Without `value`, Slider keeps its own state and starts at `defaultValue`, or at
`min` when there is none. `onValueChange` is optional then: give the slider a `name` and
a form submits its value, or read it from a ref.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Slider label="Volume" name="volume" defaultValue={40} showValue />
  }
  codes={[
    {
      code:
`<Slider label="Volume" name="volume" defaultValue={40} showValue />`,
      language: "tsx",
      label: "Uncontrolled"
    }
  ]}
/>

For two thumbs that select a range, add [`range`](#range).

## Error

`error` paints the fill and thumb in the danger palette and marks the input invalid; `errorMessage` shows under the track and is tied to the thumb with `aria-describedby`, so a screen reader reads it on focus. Both work with `range` too.

## Range

With `range`, the slider selects a `[start, end]` pair with two thumbs on one track (2.x's `RangeSlider`). `min`, `max`, `step`, `label`, `showValue`, `disabled`, `error` and `size` work as above; the value is a pair, start first.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Slider range label="Duration (minutes)" defaultValue={[20, 70]} showValue />
  }
  codes={[
    {
      code:
`<Slider range label="Duration (minutes)" defaultValue={[20, 70]} showValue />`,
      language: "tsx",
      label: "Range"
    }
  ]}
/>

Without `value` or `defaultValue`, the range starts as the whole track, `[min, max]`.

### Controlled

Pass `value` and `onValueChange` when something else owns the range, such as the filters
of a product list. `onValueChange` gets the new pair, start never above end. `formatValue`
sets how a value reads, in the readout and to a screen reader, and `minDistance`
keeps the thumbs apart.

<CodeBlock
  marginTop="16"

  label="Price"
  min={0}
  max={600}
  step={10}
  minDistance={50}
  value={range}
  onValueChange={setRange}
  formatValue={(value) => \`$\${value}\`}
  showValue
/>`,

Give the slider a `name` and a form submits both values under it, start first. Pass
two names to submit each under its own, as a search form's query string wants:

### Accessibility

The two thumbs sit in a group named by `label` (or `aria-label`). Each thumb is a
`slider` of its own, named "Minimum" and "Maximum": pass `thumbLabels` to name them
otherwise, or in another language. A thumb's bounds are the other thumb, so a
screen reader announces how far each one can go and the thumbs can never cross.

| Key | Does |
| --- | --- |
| Right / Up | One `step` higher. Left and Right swap in a right-to-left layout. |
| Left / Down | One `step` lower. |
| Page Up / Page Down | A tenth of the range higher or lower. |
| Home / End | The lowest or highest value the thumb can reach. |

A press on the track moves the nearer thumb there, and either thumb can be dragged.
When the two thumbs sit on the same value, the first move decides which one comes
along, since only one of them can go each way.
