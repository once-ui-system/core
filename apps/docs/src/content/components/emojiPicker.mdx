The `EmojiPicker` component allows you to select and insert emojis from categories.
It carries its emoji dataset, so it has its own entry point and stays out of the
root bundle: `import { EmojiPicker } from "@once-ui-system/core/emoji";`

## From a trigger

With `trigger`, the picker opens in a Dropdown from it and closes itself after a pick, controlled with `open` and `onOpenChange` or not at all. `placement` and `closeAfterClick` set where it opens and whether it closes; other Dropdown props go in `dropdownProps`. It was `EmojiPickerDropdown` in 2.x.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <BasicEmojiPickerDropdown />
  }
  codes={[
    {
      code:
`const [selectedEmoji, setSelectedEmoji] = useState("");

<Row gap="16" vertical="center">
  <EmojiPicker
    trigger={<Button label="Select Emoji" />}
    onSelect={(emoji) => setSelectedEmoji(emoji)}
  />
  {selectedEmoji && (
    <Text textVariant="heading-default-xl">
      Selected: {selectedEmoji}
    </Text>
  )}
</Row>`,
      language: "tsx",
      label: "EmojiPickerDropdown"
    }
  ]}
/>

### Controlled state

Control the open/close state externally using `open` and `onOpenChange`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <ControlledEmojiPickerDropdown />
  }
  codes={[
    {
      code:
`const [isOpen, setIsOpen] = useState(false);
const [selectedEmoji, setSelectedEmoji] = useState("");

<Row gap="16" vertical="center">
  <EmojiPicker
    trigger={<Button label="Controlled Dropdown" />}
    onSelect={(emoji) => setSelectedEmoji(emoji)}
    open={isOpen}
    onOpenChange={setIsOpen}
  />
  <Button 
    variant="secondary" 
    label={isOpen ? "Close" : "Open"} 
    onClick={() => setIsOpen(!isOpen)}
  />
  {selectedEmoji && (
    <Text textVariant="heading-default-xl">
      {selectedEmoji}
    </Text>
  )}
</Row>`,
      language: "tsx",
      label: "Controlled state"
    }
  ]}
/>
