`ArrowNavigation` is internal in Once UI 3.0. It is the arrow-key container `DropdownWrapper` and `DatePicker` use, and it is no longer exported from `@once-ui-system/core` (nor are `useArrowNavigationContext` and `withArrowNavigation`).

Use the [`useArrowNavigation`](/hooks/useArrowNavigation) hook on a container of your own: give it the container's ref and call its `handleKeyDown` from the container's `onKeyDown`. Wrap the container in [`FocusTrap`](/components/focusTrap) if focus should stay inside it.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codes={[{ code: `const listRef = useRef<HTMLDivElement>(null);
const navigation = useArrowNavigation({ layout: "column", itemCount: 3, containerRef: listRef });

return (
  <Column ref={listRef} role="listbox" tabIndex={-1} onKeyDown={navigation.handleKeyDown}>
    <Option value="1" label="One" />
    <Option value="2" label="Two" />
    <Option value="3" label="Three" />
  </Column>
);`, language: "tsx", label: "useArrowNavigation" }]}
/>
