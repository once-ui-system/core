The Kbd component is used to display keyboard keys and shortcuts with consistent styling. It's useful for showing keyboard interactions in documentation, tutorials, or application interfaces.

## Shortcuts with keys

With `keys`, Kbd draws a whole shortcut as keycaps for the reader's platform, after the action `label` names (2.x's `KeyTip`). It takes the same string [`useHotkeys`](/hooks/useHotkeys) registers, so one constant drives both and the hint cannot drift from the binding. `mod` shows as ⌘ on macOS and iOS and as Ctrl everywhere else.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Column gap="16" horizontal="center">
      <Kbd label="Search" keys="mod+k" />
      <Kbd label="Redo" keys="mod+shift+z" />
      <Kbd label="Go to inbox" keys="g i" />
      <Kbd label="Next" keys={["j", "down"]} />
    </Column>
  }
  codes={[
    {
      code:
`const SEARCH = "mod+k";

useHotkeys(SEARCH, () => setOpen(true));

<Kbd label="Search" keys={SEARCH} />
<Kbd label="Redo" keys="mod+shift+z" />
<Kbd label="Go to inbox" keys="g i" />
<Kbd label="Next" keys={["j", "down"]} />`,
      language: "tsx",
      label: "Shortcut"
    }
  ]}
/>

A space separates the steps of a sequence, drawn with "then"; an array lists
alternatives, drawn with "or". The full syntax is on the
[`useHotkeys`](/hooks/useHotkeys) page.

### In a tooltip

A hover that names the action and its keys teaches the shortcut. Pass a Kbd with `keys` as a
tooltip's label:

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Row gap="8">
      <IconButton icon="arrowLeft" variant="secondary" tooltip={<Kbd label="Undo" keys="mod+z" />} aria-label="Undo" />
      <IconButton icon="arrowRight" variant="secondary" tooltip={<Kbd label="Redo" keys="mod+shift+z" />} aria-label="Redo" />
    </Row>
  }
  codes={[
    {
      code:
`<IconButton
  icon="arrowLeft"
  tooltip={<Kbd label="Undo" keys="mod+z" />}
  aria-label="Undo"
/>`,
      language: "tsx",
      label: "Tooltip"
    }
  ]}
/>

### Screen readers

Symbols such as ⌘ and ⇧ are read inconsistently, or not at all. The keycaps are
hidden from assistive technology, and a screen reader hears the combination spelled
out instead: "Undo, Command+Z" on a Mac, "Undo, Control+Z" elsewhere.

The page renders Ctrl on the server, where the platform is unknown, and switches to
⌘ right after it hydrates on Apple platforms, without a hydration warning.
