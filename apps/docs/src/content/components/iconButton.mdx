The IconButton component provides a compact, icon-based interactive element for user actions. It's ideal for toolbar actions, navigation controls, and other UI elements where space is limited.

## Accessible name

An icon button has no text, so it needs a name for screen readers. It takes the first of `aria-label`, `ariaLabel` and a `tooltip` that is plain text, so the tooltips above already name their buttons. It is never named after its icon key. Without any of them it warns in development.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  codes={[
    {
      code:
`<IconButton icon="close" aria-label="Close dialog" />
<IconButton icon="search" ariaLabel="Search" />
<IconButton icon="copy" tooltip="Copy link" />`,
      language: "tsx",
      label: "Accessible name"
    }
  ]}
/>
