`ToggleButton` provides a flexible button-like element that can act as a toggle, tab, or segmented control. It supports selected state, prefix/suffix icons, and optional link behavior.

  marginBottom="24"

/>

## Tone

`tone` sets the palette of the selected state, as on `Button`. The default `neutral` is a grey fill; `brand`, `accent` or a status tone tints the fill and colours the label and icons, the way a sidebar marks the page you are on. `Option` takes the same prop.

  marginTop="16"
  marginBottom="24"
  preview={

      <ToggleButton tone="brand" fillWidth horizontal="start" prefixIcon="person" label="Team" />

  }

<ToggleButton tone="brand" prefixIcon="person" label="Team" />`,
