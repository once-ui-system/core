## Generating

For work that takes seconds, such as an image a model is drawing, `effect="generating"` replaces the pulse with a slow brand-to-accent mist under a fine grain of dots. It follows the theme and the brand, holds still under reduced motion, and marks itself busy. Children sit above it, so a caption can say what is happening.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Row gap="16" fillWidth s={{ direction: "column" }}>
      <Skeleton shape="block" effect="generating" radius="l" minHeight="160" aria-label="Painting logos" center>
        <Text textVariant="label-default-s" onBackground="neutral-medium">Painting logos…</Text>
      </Skeleton>
      <Skeleton shape="block" effect="generating" radius="l" minHeight="160" aria-label="Drawing the cover" />
    </Row>
  }
  codes={[
    {
      code:
`<Skeleton shape="block" effect="generating" radius="l" minHeight="160" aria-label="Painting logos" center>
  <Text textVariant="label-default-s" onBackground="neutral-medium">Painting logos…</Text>
</Skeleton>`,
      language: "tsx",
      label: "Generating"
    }
  ]}
/>
