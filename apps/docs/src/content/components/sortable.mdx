`Sortable` makes a list reorderable. Wrap the list, wrap each row in
`Sortable.Item`, and apply the new order in `onReorder`. The rows themselves
stay whatever they were: NavItems, Cards, task rows.

- **Mouse and pen:** the drag starts after a 4px move, so a click still clicks.
- **Touch:** press and hold a row for 200ms, so a tap still taps and a swipe
  still scrolls. A `Sortable.Handle` drags at once.
- **Keyboard:** Space picks a row up, the arrow keys move it, Space drops it
  and Escape puts it back. Screen readers hear "Picked up Launch plan, 1 of 5"
  and every step after.
- **Reduced motion:** the rows jump into place instead of sliding.

Sortable keeps no order of its own. It reports the move and shows whatever
order `items` holds, so the order lives in your state, next to the data.

`onReorder` gets the new order of ids and the move that made it. When your
rows are objects rather than ids, apply the move with `arrayMove`:

```tsx
onReorder={(_, { from, to }) => setTasks((tasks) => arrayMove(tasks, from, to))}
```

## A sidebar

Lists with the same `group` trade rows. Give each one a `name`, and
`onMove(id, to, from)` says where a row went, as `{ list, index }` on both
sides. Inside a [Nav](/components/nav) the rows keep the nav's spacing, and a
closed NavGroup opens when a row is held over it.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  previewPadding="24"
  preview={<SortableSidebarExample />}
  codes={[
    {
      code:
`<Nav density="compact">
  <NavSection label="Pinned">
    <Sortable group="chats" name="pinned" label="Pinned"
      items={pinned} onReorder={setPinned} onMove={move}>
      {pinned.map((chat) => (
        <Sortable.Item key={chat.id} id={chat.id}>
          <NavItem href={chat.href} icon="star" label={chat.title} />
        </Sortable.Item>
      ))}
    </Sortable>
  </NavSection>
  <NavSection label="Projects">
    <Sortable group="chats" name="projects" label="Projects"
      items={projects} onReorder={setProjects} onMove={move}>
      {/* … */}
    </Sortable>
  </NavSection>
  <NavGroup label="Archive" icon="document">
    <Sortable group="chats" name="archive" label="Archive"
      items={archive} onReorder={setArchive} onMove={move}>
      {/* … */}
    </Sortable>
  </NavGroup>
</Nav>`,
      language: "tsx",
      label: "Sidebar"
    },
    {
      code:
`const move = (id: string, to: SortablePosition, from: SortablePosition) =>
  setChats((chats) => {
    const next = { ...chats, [from.list]: chats[from.list].filter((c) => c !== id) };
    next[to.list] = next[to.list].toSpliced(to.index, 0, id);
    return next;
  });`,
      language: "tsx",
      label: "onMove"
    }
  ]}
/>

With the keyboard, an arrow key past the end of a list carries the row on into
the next list of its group. `label` names the list for screen readers: "Launch
plan, 1 of 4 in Projects".

Keep a "Move to" item in each row's menu as well. Dragging is the quick way,
not the only one.

## Handles

With `handle`, a row drags only from its `Sortable.Handle`. Use it when the
rows hold their own controls, such as a checkbox, or text people select. The
handle is a button named "Reorder" plus the row's `label`, and on a touch
screen it drags straight away with no press and hold.

  marginTop="16"
  marginBottom="24"

>
  {tasks.map((task) => (
    <Sortable.Item key={task.id} id={task.id} label={task.label} vertical="center" gap="8">
      <Sortable.Handle />
      <Checkbox label={task.label} checked={task.done} onCheckedChange={() => toggle(task.id)} />
    </Sortable.Item>
  ))}
</Sortable>`,
      language: "tsx",
      label: "Handles"
    }
  ]}
/>

## A board

The same `group` works for columns side by side. A `Sortable.Item` takes the
Flex props, so a row can be the card itself. Use `direction="row"` for a
horizontal list, such as a strip of media.

          <Sortable.Item key={card} id={card} padding="12" radius="m"
            background="surface" border="neutral-alpha-medium">
            <Text textVariant="body-default-s">{card}</Text>
          </Sortable.Item>
        ))}
      </Sortable>
    </Column>
  ))}
</Row>`,
      language: "tsx",
      label: "Board"
    }
  ]}
/>

An empty list keeps 40px of room so a row can still be dropped into it.

## Focus and screen readers

A row that holds a link or a button keeps that as its one tab stop, and Space
on it picks the row up. A row with nothing focusable becomes a tab stop itself.
Each tab stop is described with the keys to use, and one live region reads out
every pick up, move, drop and cancel. Pass `labels` to translate them:

```tsx
<Sortable
  items={rows}
  onReorder={setRows}
  labels={{
    instructions: "Leertaste zum Aufnehmen, Pfeiltasten zum Verschieben.",
    lifted: ({ item, position, total }) => `${item} aufgenommen, ${position} von ${total}.`,
  }}
>
```
