The `Text` component provides consistent typography throughout your UI, with support for variants, color tokens, alignment, and spacing. It is typically used for body content, labels, descriptions, and captions.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Column gap="12">
      <Text textVariant="body-default-m">This is default body text.</Text>
      <Text textVariant="label-strong-s">This is a strong label.</Text>
      <Text textVariant="body-strong-s">This is small, strong text.</Text>
    </Column>
  }
  codes={[
    {
      code:
`<Text textVariant="body-default-m">
    This is default body text.
</Text>
<Text textVariant="label-strong-s">
    This is a strong label.
</Text>
<Text textVariant="body-strong-s">
    This is small, strong text.
</Text>`,
      language: "tsx",
      label: "Text"
    }
  ]}
/>

## Font family

You can override the default `font-family` that comes with the variant with the `family` prop.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Column gap="16">
      <Text textVariant="body-strong-m" family="code">
        Body Strong M, but monospace
      </Text>
    </Column>
  }
  codes={[
    {
      code:
`<Text textVariant="body-strong-m" family="code">
    Body Strong M, but monospace
</Text>`,
      language: "tsx",
      label: "Font family"
    }
  ]}
/>

## Font weight

You can override the default `font-weight` inside a variant with the `weight` prop.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Column gap="16">
      <Text textVariant="body-strong-xl">
        Body Strong XL, <Text weight="default">but this is default</Text>
      </Text>
    </Column>
  }
  codes={[
    {
      code:
`<Text textVariant="heading-strong-xl">
    Text Strong XL, <Text weight="default">but this is default</Text>
</Text>`,
      language: "tsx",
      label: "Font weight"
    }
  ]}
/>

## Colors

Text color can be set using `onBackground` or `onSolid`.

      <Row gap="12" solid="neutral-medium" fillWidth radius="l" padding="12" horizontal="center">

      </Row>
      <Row gap="12" solid="accent-medium" fillWidth radius="l" padding="12" horizontal="center">

  codes={[
