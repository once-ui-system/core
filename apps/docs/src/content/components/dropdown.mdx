Dropdown is a trigger and the panel it opens, with the positioning and state management of a dropdown menu. In 3.0 it took the API of 2.x `DropdownWrapper`: the content goes in `children` (2.x `dropdown`, still accepted for one minor), and the 2.x `Dropdown` panel is internal. It provides a flexible way to create custom dropdown interfaces with various trigger elements and dropdown contents. It supports keyboard navigation when used with `Option` components.

## Basic usage

A simple dropdown with a button trigger and custom content.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Row fillWidth height="10rem" horizontal="center" vertical="start">
      <BasicDropdown />
    </Row>
  }
  codes={[
    {
      code:
`const [isOpen, setIsOpen] = useState(false);
const [selected, setSelected] = useState("");

const options = [
    { label: "Option 1", value: "option1" },
    { label: "Option 2", value: "option2" },
    { label: "Option 3", value: "option3" }
];

const handleSelect = (value: string) => {
    setSelected(value);
    setIsOpen(false);
};

return (
    <Dropdown
      open={isOpen}
      onOpenChange={setIsOpen}
      trigger={
        <Button 
          variant="secondary" 
          suffixIcon="chevronDown"
          onClick={() => setIsOpen(!isOpen)}
        >
          {selected ? options.find(opt => opt.value === selected)?.label : "Select an option"}
        </Button>
      }><Column minWidth="10rem" padding="4" gap="2">
          {options.map((option) => (
            <Option
              key={option.value}
              label={option.label}
              value={option.value}
              selected={option.value === selected}
              onClick={handleSelect}
            />
          ))}
        </Column></Dropdown>
);`,
      language: "tsx",
      label: "Dropdown"
    }
  ]}
/>

## Custom

Control the dimensions of the dropdown menu.

      code:
`const [isOpen, setIsOpen] = useState(false);
const [selected, setSelected] = useState("");
const [searchQuery, setSearchQuery] = useState("");

const options = [
    { label: "Apple", value: "apple", description: "Fruit" },
    { label: "Banana", value: "banana", description: "Fruit" },
    { label: "Carrot", value: "carrot", description: "Vegetable" },
    { label: "Broccoli", value: "broccoli", description: "Vegetable" },
    { label: "Orange", value: "orange", description: "Fruit" }
];

const handleSelect = (value: string) => {
    setSelected(value);
    setIsOpen(false);
};

const filteredOptions = options.filter(option => 
    option.label.toLowerCase().includes(searchQuery.toLowerCase())
);

return (
    <Dropdown
      open={isOpen}
      onOpenChange={setIsOpen}
      minHeight="200px"
      trigger={
        <Button 
          variant="secondary" 
          suffixIcon="chevronDown"
          onClick={() => setIsOpen(!isOpen)}
        >
          {selected ? options.find(opt => opt.value === selected)?.label : "Search items"}
        </Button>
      }><Column fillWidth minWidth="12rem">
          <Column padding="4" fillWidth position="sticky" top="0" background="surface" zIndex={1}>
            <Input
              size="s"
              id="search-dropdown"
              placeholder="Search"
              prefix={<Icon name="search" size="xs" />}
              value={searchQuery}
              onChange={(e) => setSearchQuery(e.target.value)}
              onClick={(e) => e.stopPropagation()}
            />
          </Column>
          <Column fillWidth gap="2" padding="4">
            {filteredOptions.length > 0 ? (
              filteredOptions.map((option) => (
                <Option
                  key={option.value}
                  label={option.label}
                  value={option.value}
                  description={option.description}
                  selected={option.value === selected}
                  onClick={handleSelect}
                />
              ))
            ) : (
              <Flex fillWidth center paddingX="16" paddingY="32">
                <Text>No results found</Text>
              </Flex>
            )}
          </Column>
        </Column></Dropdown>
);`,
      language: "tsx",
      label: "Custom"
    }
  ]}
/>

## Where it opens

A panel opens on the option marked `aria-selected="true"`, scrolled into view
inside the panel, the way a native select opens on the value it is already
showing. `Option` sets that attribute from its `selected` prop, so a list built
from `Option` needs nothing further. With no selection the panel opens on its
first enabled option; a selected option that is disabled is skipped.

A panel that leads with something other than its list — a searchable `Select`
and its query field — opens on that instead.

## Button triggers

A `Button` or `IconButton` passed as the `trigger` renders a real
`<button type="button">` with `aria-haspopup` and `aria-expanded`, so the
dropdown opens from the keyboard as well as the mouse. There is no need to add
`type="button"` or an empty `onClick` to make it one. A disabled trigger does not
open the dropdown.

## Context menu

`openOn="contextmenu"` opens the Dropdown at the pointer on right-click (or the context menu key) over its `trigger`, as a `menu` of `menuitem`s that stays on screen. `contents` renders no box around the trigger. It was `ContextMenu` in 2.x, which took the region as children and the menu as `dropdown`.

### Keyboard and screen readers

The menu opens at the pointer, or at the element when it is opened from the keyboard (Shift+F10 or the Menu key). Near the right or bottom edge of the screen it opens to the left of or above the pointer, so it stays on screen. It is a `menu` and its Options are `menuitem`s: the arrow keys move between them, skipping disabled ones and wrapping at the ends, Home and End jump to the first and last, and Escape closes it and returns focus to where it was.

### Without a wrapper box

`Dropdown openOn="contextmenu"` wraps its children in a box. Set `contents` to render the wrapper with `display: contents` instead, so it adds nothing to the layout: an absolutely positioned child still positions against its own ancestors, and a grid or flex item stays one. A timeline clip or a table row can take a context menu this way without a hand-made one. With `contents` there is no box for `className`, `style` or the disabled dimming to style.

  marginBottom="24"
  codes={[

`<Grid columns="3" gap="8">
  {files.map((file) => (
    <Dropdown openOn="contextmenu" trigger={<FileTile file={file} />} key={file.id} contents><FileMenu file={file} /></Dropdown>
  ))}
</Grid>`,
