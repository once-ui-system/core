Eighty components is a lot to scroll past alphabetically. This groups them by
the job they do, so you can find the one you need without knowing its name.

If you are new, start with [Structure](/basics/structure) — layout is the part
everything else sits inside.

## Layout

The primitives, and the containers built from them.

- [Flex](/components/flex) — the layout primitive; one axis, and every shared prop
- [Grid](/components/grid) — two-dimensional layout with a responsive column count
- [MasonryGrid](/components/masonryGrid) — columns for items of uneven height
- [SplitView](/components/splitView) — two resizable panes, collapsing to tabs when narrow
- [Line](/components/line) — a rule, horizontal or vertical
- [Mask](/components/mask) — reveal content through a shape or cursor-following window

## Surfaces

Things that hold other things.

- [Card](/components/card) — a surface that can be selected or clicked
- [Background](/components/background) — gradients, dots, grids and lines behind a section
- [Fade](/components/fade) — an edge that dissolves into the surface behind it
- [Banner](/components/banner) — a full-width strip for an announcement
- [Book](/components/book) — a 3D cover, for showing a publication

## Content

- [Heading](/components/heading) — headings on the type scale
- [Text](/components/text) — everything else on the type scale
- [BlockQuote](/components/blockquote) — a pulled quote
- [InlineCode](/components/inlineCode) — code inside a sentence
- [Kbd](/components/kbd) — a key or shortcut
- [List](/components/List) — ordered and unordered lists
- [Table](/components/table) — sortable, selectable, paginated rows
- [Timeline](/components/timeline) — events in order
- [Media](/components/media) — images and video, with the framework's optimizer when there is one
- [MediaPlayers](/components/mediaPlayers) — audio and video with real controls
- [CompareImage](/components/compareImage) — two images under a draggable divider
- [Logo](/components/logo) / [LogoCloud](/components/logoCloud) — a mark, and a grid of them
- [OgCard](/components/ogCard) — a link rendered as its own preview

## Navigation

- [SmartLink](/components/smartLink) — the link, routed through the framework adapter
- [Button](/components/button) / [IconButton](/components/iconButton) / [ToggleButton](/components/toggleButton)
- [SegmentedControl](/components/segmentedControl) — one choice from a small set
- [Dropdown](/components/dropdown) / [Option](/components/option) — a trigger and the menu it opens
- [Dropdown `openOn="contextmenu"`](/components/dropdown#context-menu) — a menu on right-click
- [User `dropdown`](/components/user#menu) — the account menu
- [NavIcon](/components/navIcon) — the hamburger, animated
- [ScrollToTop](/components/scrollToTop) — the button that comes back on scroll

## Overlays

- [Dialog](/components/dialog) — a modal, stackable
- [Dialog `variant="sheet"`](/components/dialog#sheet) — a full-height sheet with an optional backdrop
- [Tooltip](/components/tooltip) — a label on hover
- [HoverCard](/components/hoverCard) — a preview on hover
- [Tooltip `content`](/components/tooltip#info-icon) — an info icon that explains a field
- [Toast](/components/toast) — transient confirmation
- [EmojiPicker](/components/emojiPicker), inline or from a `trigger`

## Status and feedback

- [Spinner](/components/spinner) — work in progress, duration unknown
- [Skeleton](/components/skeleton) — the shape of content that has not arrived
- [ProgressBar](/components/progressBar) — work in progress, duration known
- [StatusIndicator](/components/statusIndicator) — a state dot
- [Tag](/components/tag) — a label, an announcement or a toggle (Badge and Chip in 2.x)
- [Feedback](/components/feedback) — an inline message with a severity
- [Pulse](/components/pulse) — a live indicator

## Identity

- [Avatar](/components/avatar) / [AvatarGroup](/components/avatarGroup) — a person, and several
- [User](/components/user) — avatar, name and detail as one unit
- [Icon](/components/icon) — the icon set, typed by name

## Scrolling

- [Scroller](/components/scroller) — a scrollable strip with arrow affordances
- [Scroller](/components/scroller#track-mode) track mode — a run of tiles with drag, wrap-around and markers
- [Carousel](/components/carousel) — one item at a time, cross-fading or snapping (`mode="snap"`)
- [Scroller `auto`](/components/scroller#auto) — a continuously moving strip
- [InfiniteScroll](/components/infiniteScroll) — load more as it comes into view
- [ScrollLock](/components/scrollLock) — freeze the page behind an overlay

## Motion

- [RevealFx](/effects/revealFx) — enter on scroll
- [Animation](/components/animation) — the primitive the rest are built on
- [HoverCard `placement="cover"`](/components/hoverCard#cover) — content over its trigger on hover
- [Scrubber](/components/scrubber) — a playhead over time

See [Effects](/effects/effect) for the ambient layers — blobs, matrix, weather,
glitch, holo and the rest.

## Theming

- [ThemeSwitcher](/components/themeSwitcher) — light, dark, system
- [StylePanel](/components/stylePanel) — the full customization surface, composable
- [StyleOverlay](/components/styleOverlay) — the panel in a floating shell
- [Setting](/components/setting) — one labelled control, for building your own

## Behaviour

Components with no UI of their own.

- [FocusTrap](/components/focusTrap) — keep focus inside an overlay
- [useArrowNavigation](/hooks/useArrowNavigation) — arrow keys across a collection (a hook)
- [HoverCard `placement="cursor"`](/components/hoverCard#cursor) — content that follows the pointer
