`User` is a compact component used to represent a user or persona. It combines an avatar, primary name, optional subline, and a status or role tag.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <User
      name="Lorant One"
      subline="Design Engineer"
      tagProps={{ label: "Admin", variant: "accent" }}
      avatarProps={{ src: "/images/avatar.jpg" }}
    />
  }
  codes={[
    {
      code:
`<User
    name="Lorant One"
    subline="Design Engineer"
    tagProps={{ label: "Admin", variant: "accent" }}
    avatarProps={{ src: "/images/avatar.jpg" }}
/>`,
      language: "tsx",
      label: "User"
    }
  ]}
/>

## Loading

Display skeletons with the `loading` prop to show a graceful placeholder before data is available.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <User loading name="Lorant One" subline="Design Engineer" />
  }
  codes={[
    {
      code:
`<User loading name="Lorant One" subline="Design Engineer" />`,
      language: "tsx",
      label: "Loading"
    }
  ]}
/>

## Custom content

You can override the default layout using `children`. This is useful for inline customization (e.g. badges, quick actions).

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <User avatarProps={{ value: "Q" }}>
      <Column paddingX="8">
        <Text textVariant="label-default-m">
          Quasar
        </Text>
        <Text textVariant="body-default-xs" onBackground="neutral-weak">
          Cyberforge
        </Text>
      </Column>
    </User>
  }
  codes={[
    {
      code:
`<User avatarProps={{ value: "Q" }}>
    <Column paddingX="8">
      <Text textVariant="label-default-m">
        Quasar
      </Text>
      <Text textVariant="body-default-xs" onBackground="neutral-weak">
        Cyberforge
      </Text>
    </Column>
</User>`,
      language: "tsx",
      label: "Custom content"
    }
  ]}
/>

## Menu

With `dropdown`, the User is the trigger of an account menu; `selected`, `placement`, `minWidth`, `maxWidth` and `minHeight` set the trigger state and the menu. It was `UserMenu` in 2.x.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <User
      name="Lorant One"
      subline="Design Engineer"
      placement="right-end"
      avatarProps={{ src: "/images/avatar.jpg" }}
      dropdown={
        <Column gap="4" padding="4" minWidth="10rem">
          <ClientOption fillWidth prefix={<Icon size="xs" onBackground="neutral-weak" name="settings" />} label="Settings" />
          <ClientOption fillWidth prefix={<Icon size="xs" onBackground="neutral-weak" name="logout" />} label="Log out" />
        </Column>
      }
    />
  }
  codes={[
    {
      code:
`<User
    name="Lorant One"
    subline="Design Engineer"
    placement="right-end"
    avatarProps={{ src: "/images/avatar.jpg" }}
    dropdown={
      <Column gap="4" padding="4" minWidth="10rem">
        <Option fillWidth prefix={<Icon size="xs" onBackground="neutral-weak" name="settings" />} label="Settings" />
        <Option fillWidth prefix={<Icon size="xs" onBackground="neutral-weak" name="logout" />} label="Log out" />
      </Column>
    }
/>`,
      language: "tsx",
      label: "UserMenu"
    }
  ]}
/>

### Loading state

You can show skeleton content while loading profile data by setting `loading={true}`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <User loading dropdown={null} />
  }
  codes={[
    {
      code:

      language: "tsx",
      label: "Loading"
    }

/>
