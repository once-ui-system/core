## Theme roles

A role (`brand`, `accent`, `neutral`, `info`, `danger`, `warning`, `success`) takes the colour
the theme assigns it, so `danger` follows the app's danger scheme. A palette name stays that
fixed colour; `rose`, `mint`, `dusk`, `sand` and `slate` are there as well.
