The Logo component is used to display brand logos with consistent styling and sizing. It supports displaying both an icon and a wordmark, either separately or together.

## Text wordmark

For a brand with no wordmark file, `text` sets the name in the heading font at the logo's size,
after the icon if there is one. A link is then named by the text.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Row gap="24" center>
      <Logo icon="/trademarks/icon-dark.svg" text="Acme" size="s" />
      <Logo text="Acme" size="l" />
    </Row>
  }
  codes={[
    {
      code:
`<Logo icon="/trademarks/icon-dark.svg" text="Acme" size="s" />
<Logo text="Acme" size="l" />`,
      language: "tsx",
      label: "Text wordmark"
    }

## Monogram

For a brand with no designed icon yet, `monogram` draws one from the theme: a square tile at the
logo's height in the brand colour (even under the "contrast" solid setting), holding the first letter of `text` in the heading font.
It follows the brand colour, radius, solid style and light or dark mode, so no placeholder SVG is
needed. Pass a string to choose the letters. Beside `text` the tile is decorative. When the real
mark exists, pass it as `icon`: an icon always replaces the monogram.

  marginTop="16"
  marginBottom="24"

## Brand

The `brand` prop provides a `copy` option for allowing the icon and wordmark to be separately copied as an svg to the clipboard on right click through a context menu. The `url` option displays a link to your brand page when provided.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <>
      <Logo light icon="/trademarks/icon-light.svg" wordmark="/trademarks/type-light.svg" brand={{ copy: true, url: "https://once-ui.com/brand" }} />
      <Logo dark icon="/trademarks/icon-dark.svg" wordmark="/trademarks/type-dark.svg" brand={{ copy: true, url: "https://once-ui.com/brand" }} />
    </>
  }
  codes={[
    {
      code:
`<Logo
    wordmark="/trademarks/type-dark.svg"
    brand={{
      copy: true,
      url: "https://once-ui.com/brand"
    }}
/>`,
      language: "tsx",
      label: "Brand"
    }
  ]}
/>
