## Selected

Use `selected` to mark the chosen card in a set — a plan picker, a template
gallery, a multi-select list. It repaints the border and background from the
brand scheme, and a card that is also clickable announces the state as a
pressed toggle. Both colours are defaults, so passing `background` or `border`
still wins.
