The Icon component is used to display vector icons throughout your application. It provides consistent styling with various sizes and colors to enhance visual communication.

## Motion

Seventeen built-in icons move, with CSS alone. `animate` plays an icon's own motion on the trigger it is made for; `active` is the on state of the icons that follow one, and implies `animate`.

<CodeBlock
  marginTop="16"
  marginBottom="24"
  preview={
    <Column gap="16" horizontal="center">
      <Row gap="8" wrap horizontal="center">
        <Button variant="secondary" size="s" prefixIcon="bell">Notifications</Button>
        <Button variant="secondary" size="s" prefixIcon="trash">Delete</Button>
        <Button variant="secondary" size="s" prefixIcon="refresh">Refresh</Button>
        <Button variant="secondary" size="s" suffixIcon="arrowRight">Continue</Button>
      </Row>
      <Row gap="24" horizontal="center">
        <Icon name="check" animate size="l" />
        <Icon name="chevronDown" active size="l" />
        <Icon name="plus" active size="l" />
        <Icon name="heart" active size="l" />
        <Icon name="checkbox" active size="l" />
        <Icon name="menu" active size="l" />
      </Row>
    </Column>
  }
  codes={[
    {
      code:
`// Moves while the button is hovered or keyboard-focused: Button does this for you
<Button prefixIcon="bell">Notifications</Button>

// Draws itself in when it appears (mount it when the save lands)
{saved && <Icon name="check" animate />}

// Follow a state
<Icon name="chevronDown" active={open} />   // flips
<Icon name="plus" active={adding} />        // turns into a cross
<Icon name="heart" active={liked} />        // fills with a beat
<Icon name="checkbox" active={checked} />   // fills, then ticks; empty when off
<Icon name="menu" active={open} />          // folds into a cross`,
      language: "tsx",
      label: "Motion"
    }
  ]}
/>

| Icon | Trigger | Motion |
| --- | --- | --- |
| `check` | in | the short leg goes quickly, the long leg settles, a small pop |
| `checkbox` | active | the box fills, then the tick draws through it |
| `bell` | hover | the body swings from its top, the clapper lags a beat |
| `plus` | active | turns into a cross, for add buttons that become cancel |
| `chevronDown`, `chevronUp`, `chevronLeft`, `chevronRight` | active | flips |
| `arrowRight`, `arrowLeft`, `arrowUp`, `arrowDown` | hover | leans the way it points |
| `refresh` | hover | one full turn |
| `eye` | hover | blinks |
| `heart` | active | the line turns solid with a beat |
| `trash` | hover | the lid lifts and tips |
| `menu` | active | three lines fold into a cross ([NavIcon](/components/navIcon)) |

- **Triggers.** `animate` (or `animate={true}`) uses the trigger above. `"hover"` plays while the icon or the control around it (a link, button, menu item, option, tab, label or summary) is hovered or keyboard-focused; `"in"` plays once when the icon appears; `"active"` follows `active`. Icons without a motion ignore both props.
- **Components do it for you.** `Button`, `IconButton` and `ToggleButton` move a bell, trash, refresh, eye or arrow icon on hover; `ToggleButton` passes `selected` to a heart or plus. `Accordion` flips its chevron (or turns its plus into a cross), `Select` flips its chevron, `Checkbox` draws its tick in when checked, and `NavIcon` folds the menu icon.
- **Timing follows the shape.** The theme's [border](/basics/border) sets it: `playful` 420ms with an overshoot, `rounded` 320ms with a soft settle, `conservative` 200ms, exact, no pop. The tokens are `--icon-motion-duration`, `--icon-motion-ease`, `--icon-motion-ease-out` and `--icon-motion-pop`.
- **Reduced motion.** Under `prefers-reduced-motion`, or a theme with micro transitions off, nothing moves; states still change.
- **Your own icons.** An icon you register under one of these names still turns, flips and leans as a whole; motions that move one part (bell, trash, check, checkbox, menu) need the built-in drawing.

## Icon library

Once UI ships its own icons: 178 names drawn in one line style. The SVG data is
inlined in the package, so no icon dependency is installed with it.

`name` is typed as `IconName`, a union of those names, so a typo is a build
error rather than a blank space at runtime. To add your own icons, from
[react-icons](https://react-icons.github.io/react-icons/), another set, or
hand-written SVG, and to extend that union with them, see
[IconProvider](/contexts/iconProvider).

### Coming from 2.x

The icons were redrawn for 3.0 under the same names, and two of them now draw
something else:

| Name | 2.x drew | 3.0 draws | To keep the 2.x look |
| --- | --- | --- | --- |
| `check` | a check in a circle | the plain check mark | `checkCircle` |
| `checkbox` | the plain check mark | a ticked box | `check` |

`document` now draws a page, and `text` draws the lines it used to. The 3.0
codemod reports every use of these names without rewriting them. See the
[migration guide](https://github.com/once-ui-system/core/blob/main/MIGRATING.md#15-icons-are-once-uis-own).
