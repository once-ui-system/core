Once UI manages typography properties with the [`Text`](/components/text) and 
[`Heading`](/components/heading) components. They apply utility classes and CSS variables under the hood. See the [Config](/config) page for our recommended font setup.

## Font weight

Add `font-weight` classes to elements. The value adjusts to the adjacent or closest parent `font-family` class.

<Table
  marginTop="16"
  marginBottom="24"
  data={{
    headers: [
      { content: "Class" },
      { content: "Variable" },
    ],
    rows: [
      [".font-weight-inherit", "—"],
      [".font-default", "--font-weight-display-default"],
      [".font-normal", "--font-weight-display-normal"],
      [".font-medium", "--font-weight-display-medium"],
      [".font-strong", "--font-weight-display-strong"]
    ]
  }}
/>

Every family reads the display weights unless you give it its own: `--font-<family>-weight-<weight>`, for `heading`, `body`, `label` and `code`. Setting one changes only that family, so bolder body text leaves headlines and labels alone.

```css
:root {
  --font-body-weight-strong: 700;  /* body-strong-* */
  --font-label-weight-strong: 500; /* label-strong-* */
}
```
